MTS.ContextMenu

Right-click context menu — icons, shortcuts, groups, dividers, danger items, long-press mobile.

1 — En zona delimitada / On a specific zone
🖱️ Click derecho aquí / Right-click here
— haz click derecho en la zona —
<div id="my-zone">Right-click here</div> <script> new MTS.ContextMenu('#my-zone', { items: [ { id: 'copy', label: 'Copy', shortcut: '⌘C' }, { id: 'cut', label: 'Cut', shortcut: '⌘X' }, { id: 'paste', label: 'Paste', shortcut: '⌘V' }, { divider: true }, { id: 'delete', label: 'Delete', danger: true }, ], // Fires when menu opens / Se dispara al abrir onOpen: (e) => console.log('opened at', e.detail.x, e.detail.y), // Fires when menu closes / Se dispara al cerrar onClose: () => console.log('closed'), // Fires when item selected / Se dispara al seleccionar un ítem onSelect: (e) => { console.log(e.detail.id); // → 'copy' console.log(e.detail.item); // → { id, label, ... } }, }); </script>
new MTS.ContextMenu('#my-zone', { items: [ { id: 'copy', label: 'Copy', shortcut: '⌘C' }, { id: 'cut', label: 'Cut', shortcut: '⌘X' }, { id: 'paste', label: 'Paste', shortcut: '⌘V' }, { divider: true }, // danger: true — red danger style / estilo de peligro rojo { id: 'delete', label: 'Delete', danger: true }, ], // Fires when menu opens / Se dispara al abrir el menú onOpen: (e) => { console.log('opened at', e.detail.x, e.detail.y); }, // Fires when menu closes / Se dispara al cerrar el menú onClose: () => console.log('closed'), // Fires when item selected / Se dispara al seleccionar un ítem onSelect: (e) => { console.log(e.detail.id); // → 'copy' console.log(e.detail.item); // → { id, label, shortcut } }, });
2 — Con grupos e íconos / With groups and icons
🖱️ Click derecho aquí / Right-click here
— haz click derecho en la zona —
<div id="my-zone">Right-click here</div> <script> new MTS.ContextMenu('#my-zone', { items: [ { group: 'File' }, { id: 'open', label: 'Open', icon: ICON_FOLDER }, { id: 'save', label: 'Save', icon: ICON_SAVE, shortcut: '⌘S' }, { divider: true }, { group: 'Edit' }, { id: 'copy', label: 'Copy', icon: ICON_COPY, shortcut: '⌘C' }, { id: 'paste', label: 'Paste', icon: ICON_PASTE, shortcut: '⌘V', disabled: true }, { divider: true }, { id: 'delete', label: 'Delete', icon: ICON_TRASH, danger: true }, ], onSelect: (e) => console.log(e.detail.id), }); </script>
new MTS.ContextMenu('#my-zone', { items: [ // group: label above items / etiqueta de grupo { group: 'File' }, { id: 'open', label: 'Open', icon: ICON_FOLDER }, { id: 'save', label: 'Save', icon: ICON_SAVE, shortcut: '⌘S' }, { divider: true }, { group: 'Edit' }, { id: 'copy', label: 'Copy', icon: ICON_COPY, shortcut: '⌘C' }, { id: 'paste', label: 'Paste', icon: ICON_PASTE, shortcut: '⌘V', disabled: true }, { divider: true }, // danger: true — red style / estilo rojo { id: 'delete', label: 'Delete', icon: ICON_TRASH, danger: true }, ], onSelect: (e) => console.log(e.detail.id), // Per-item onClick also works / onClick por ítem también funciona // onClick: (item) => console.log(item.id) });
