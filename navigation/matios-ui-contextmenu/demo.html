MTS.ContextMenu

Menú contextual con click derecho o long press.

1 — En zona delimitada
🖱️ Click derecho aquí para ver el menú contextual
— interactúa —
new MTS.ContextMenu('#zona', {
  items: [
    { label:'Ver detalle',  icon:MTS.Icon.get('eye'),    onClick:(item) => {} },
    { label:'Editar',       icon:MTS.Icon.get('edit-2'), onClick:(item) => {} },
    { divider: true },
    { label:'Eliminar', icon:MTS.Icon.get('trash'), danger:true, onClick:(item) => {} },
  ],
  onSelect: (e) => console.log('seleccionado:', e.item.label),
})
2 — Con grupos y shortcuts
🖱️ Click derecho — menú con grupos y shortcuts
new MTS.ContextMenu('#zona', {
  items: [
    { group: 'Archivo' },
    { label:'Abrir',  shortcut:'⌘O', onClick:(item) => {} },
    { label:'Guardar',shortcut:'⌘S', onClick:(item) => {} },
    { divider: true },
    { group: 'Edición' },
    { label:'Copiar',  shortcut:'⌘C', onClick:(item) => {} },
    { label:'Pegar',   shortcut:'⌘V', onClick:(item) => {} },
  ],
})
