MTS.Pagination

Full pagination — page size selector, record summary, jump-to-page, size variants.

1 — Básico con onChange / Basic with onChange
— cambia de página —
<div id="my-pagination" data-total="250" data-page="1" data-page-size="25"> </div> <script> new MTS.Pagination('#my-pagination', { // Fires on page or page size change / Se dispara al cambiar página o page size onChange: (e) => { console.log(e.detail.page); // → 3 console.log(e.detail.pageSize); // → 25 console.log(e.detail.from); // → 51 console.log(e.detail.to); // → 75 fetchData(e.detail.page, e.detail.pageSize); }, }); </script>
new MTS.Pagination('#my-pagination', { total: 250, page: 1, pageSize: 25, showSizes: true, // page size selector / selector de page size showInfo: true, // "Showing 1-25 of 250" // Fires on page or page size change / Se dispara al cambiar página o page size onChange: (e) => { console.log(e.detail.page); // → current page console.log(e.detail.pageSize); // → current page size console.log(e.detail.from); // → first record console.log(e.detail.to); // → last record console.log(e.detail.total); // → total records fetchData(e.detail.page, e.detail.pageSize); }, });
2 — Con jump + tamaños / With jump + sizes
size: sm + showJump
size: md (default)
size: lg
<div id="pag-sm" data-total="500" data-size="sm"></div> <div id="pag-md" data-total="500" data-size="md"></div> <div id="pag-lg" data-total="500" data-size="lg"></div> <script> ['sm','md','lg'].forEach(s => new MTS.Pagination('#pag-' + s, { total: 500, size: s, showJump: s === 'sm', }) ); </script>
// Small with jump-to-page / Pequeño con ir a página new MTS.Pagination('#pag-sm', { total: 500, size: 'sm', showJump: true, // input to jump to any page / input para ir a cualquier página }); // Medium (default) / Mediano new MTS.Pagination('#pag-md', { total: 500, size: 'md' }); // Large / Grande new MTS.Pagination('#pag-lg', { total: 500, size: 'lg' });
3 — API — setPage, setTotal, setPageSize
— usa los botones —
<div id="my-pagination" data-total="250"></div> <script> const pag = new MTS.Pagination('#my-pagination', { onChange: (e) => fetchData(e.detail.page, e.detail.pageSize), }); pag.setPage(3) pag.setTotal(500) pag.setPageSize(50) pag.getState() // → { page, pageSize, total, from, to } </script>
const pag = new MTS.Pagination('#my-pagination', { total: 250, pageSize: 25, onChange: (e) => fetchData(e.detail.page, e.detail.pageSize), }); // Navigate / Navegar pag.setPage(3) // Update total after data load / Actualizar total tras cargar datos pag.setTotal(500) // Change page size (resets to page 1) / Cambiar page size (resetea a página 1) pag.setPageSize(50) // Get current state / Obtener estado actual pag.getState() // → { page: 1, pageSize: 50, total: 500, from: 1, to: 50 }
4 — siblings — páginas visibles a cada lado
siblings: 1 (default)
siblings: 2
<div id="pag-sib1" data-total="500"></div> <div id="pag-sib2" data-total="500"></div> <script> new MTS.Pagination('#pag-sib1', { total:500, page:5, showSizes:false, showInfo:false, siblings:1 }); new MTS.Pagination('#pag-sib2', { total:500, page:5, showSizes:false, showInfo:false, siblings:2 }); </script>
// siblings: pages shown on each side of the active page // siblings: páginas mostradas a cada lado de la activa new MTS.Pagination('#pag-sib1', { total: 500, page: 5, siblings: 1, // default: «1 2 3 [4] 5 6 7» showSizes: false, showInfo: false, }); new MTS.Pagination('#pag-sib2', { total: 500, page: 5, siblings: 2, // «1 2 3 4 [5] 6 7 8 9» showSizes: false, showInfo: false, });
