MTS.SideNav

Collapsible sidebar — submenus, badges, groups, dividers, accordion mode.

1 — Completo con submenús y badges / Full with submenus and badges
← Selecciona un ítem
— selecciona un ítem del menú —
<div id="sidebar"></div> <script> new MTS.SideNav('#sidebar', { active: 'dashboard', items: [ { group: 'Main' }, { id: 'dashboard', label: 'Dashboard', icon: ICON_GRID, href: '/dashboard' }, { id: 'analytics', label: 'Analytics', icon: ICON_CHART, badge: 'NEW' }, { id: 'products', label: 'Products', icon: ICON_BOX, children: [ { id: 'products-list', label: 'All products' }, { id: 'products-create', label: 'Add product' }, ]}, { divider: true }, { group: 'Settings' }, { id: 'settings', label: 'Settings', icon: ICON_COG }, ], // Fires when active item changes / Se dispara al cambiar el ítem activo onChange: (e) => console.log(e.detail.id), // Fires when nav collapses/expands / Se dispara al colapsar/expandir onCollapse: (e) => console.log(e.detail.collapsed), }); </script>
const nav = new MTS.SideNav('#sidebar', { active: 'dashboard', accordion: true, // one submenu open at a time / un submenú abierto a la vez items: [ { group: 'Main' }, { id: 'dashboard', label: 'Dashboard', icon: ICON_GRID }, { id: 'analytics', label: 'Analytics', icon: ICON_CHART, badge: 'NEW' }, // Submenu / Submenú { id: 'products', label: 'Products', icon: ICON_BOX, children: [ { id: 'products-list', label: 'All products' }, { id: 'products-create', label: 'Add product' }, ]}, // Divider + group / Separador + grupo { divider: true }, { group: 'Settings' }, { id: 'settings', label: 'Settings', icon: ICON_COG }, { id: 'disabled', label: 'Disabled', icon: ICON_BAN, disabled: true }, ], // Fires when active item changes / Se dispara al cambiar el ítem activo onChange: (e) => { console.log(e.detail.id); // → 'analytics' console.log(e.detail.item); // → { id, label, ... } }, // Fires when nav collapses or expands / Se dispara al colapsar o expandir onCollapse: (e) => console.log('collapsed:', e.detail.collapsed), });
2 — Colapsable + API
← Usa los botones para controlar el nav
— usa los botones —
<button id="btn-toggle">Toggle</button> <div id="sidebar"></div> <script> const nav = new MTS.SideNav('#sidebar', { collapseBtn: '#btn-toggle', // external button / botón externo items: [...], onCollapse: (e) => console.log(e.detail.collapsed), }); nav.collapse() nav.expand() nav.toggleCollapse() nav.setActive('analytics') nav.setBadge('inbox', 5) nav.setBadge('inbox', null) // clear / limpiar </script>
const nav = new MTS.SideNav('#sidebar', { active: 'dashboard', // Start collapsed / Iniciar colapsado collapsed: false, items: [...], onChange: (e) => console.log('active:', e.detail.id), onCollapse: (e) => console.log('collapsed:', e.detail.collapsed), }); // API nav.collapse() // collapse to icons only / colapsar a solo íconos nav.expand() // expand / expandir nav.toggleCollapse() // toggle / alternar nav.setActive('analytics') // set active item / establecer ítem activo nav.setBadge('inbox', 5) // set badge / establecer badge nav.setBadge('inbox', null) // clear badge / limpiar badge
