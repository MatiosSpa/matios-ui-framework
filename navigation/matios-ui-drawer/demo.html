MTS.Drawer

Panel lateral deslizante — derecha, izquierda, arriba o abajo.

1 — Posiciones
— abre un drawer —
const drawer = new MTS.Drawer({
  title:    'Filtros',
  position: 'right',    // 'right'|'left'|'top'|'bottom'
  size:     'md',       // 'sm'|'md'|'lg'|'full'
  content:  '<p>Contenido HTML...</p>',
  footer:   '<button onclick="drawer.hide()">Cerrar</button>',
  backdrop:  true,      // cierra al click fuera
  onOpen:  () => console.log('abierto'),
  onClose: () => console.log('cerrado'),
})
drawer.show()
drawer.hide()
2 — Tamaños
new MTS.Drawer({ position:'right', size:'sm',   content:'...' })
new MTS.Drawer({ position:'right', size:'md',   content:'...' })
new MTS.Drawer({ position:'right', size:'lg',   content:'...' })
new MTS.Drawer({ position:'right', size:'full', content:'...' })
3 — Static (no cierra con Esc ni backdrop)
new MTS.Drawer({
  title:   'Formulario obligatorio',
  static:   true,    // no cierra con Esc ni click fuera
  content: '...',
  footer:  '<button onclick="d.hide()">Aceptar y cerrar</button>',
})
