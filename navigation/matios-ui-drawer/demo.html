MTS.Drawer

Sliding side panel — left, right, top, bottom · sm/md/lg/full · static mode.

1 — Posiciones / Positions
— abre un drawer —
<!-- MTS.Drawer has no HTML container — it appends to body MTS.Drawer no tiene contenedor HTML — se agrega al body --> <button onclick="drawer.show()">Open drawer</button> <script> const drawer = new MTS.Drawer({ title: 'Filters', content: '<p>Filter options here</p>', position: 'right', // 'left' | 'right' | 'top' | 'bottom' size: 'md', // 'sm' | 'md' | 'lg' | 'full' // Fires when drawer opens / Se dispara al abrir onOpen: () => console.log('opened'), // Fires when drawer closes / Se dispara al cerrar onClose: () => console.log('closed'), }); </script>
// Right (default) / Derecha const rightDrawer = new MTS.Drawer({ title: 'Filters', content: '<p>Filter panel</p>', position: 'right', size: 'md', onOpen: () => console.log('opened'), onClose: () => console.log('closed'), }); // Left navigation / Navegación izquierda const leftDrawer = new MTS.Drawer({ title: 'Navigation', content: '<nav><ul><li>Home</li><li>Products</li></ul></nav>', position: 'left', size: 'sm', }); // Bottom sheet const bottomSheet = new MTS.Drawer({ title: 'Options', position: 'bottom', size: 'sm', content: '<ul>...</ul>', });
2 — Tamaños / Sizes
<button onclick="drawer.show()">Open</button> <script> const drawer = new MTS.Drawer({ size: 'lg', // 'sm' | 'md' | 'lg' | 'full' title: 'Large drawer', content: '...', }); </script>
// Size: 'sm' | 'md' | 'lg' | 'full' / Tamaño new MTS.Drawer({ size: 'sm', title: 'Small', content: '...' }); new MTS.Drawer({ size: 'md', title: 'Medium', content: '...' }); // default new MTS.Drawer({ size: 'lg', title: 'Large', content: '...' }); new MTS.Drawer({ size: 'full', title: 'Full', content: '...' });
3 — Static (no cierra con Esc/backdrop) + API
<!-- static: true — user must click a button to close static: true — el usuario debe hacer click en un botón para cerrar --> <button onclick="drawer.show()">Open</button> <script> const drawer = new MTS.Drawer({ title: 'Confirm action', content: '<p>Are you sure?</p>', footer: '<button onclick="drawer.hide()">Cancel</button> <button>Confirm</button>', static: true, // no Esc / no backdrop click }); </script>
const drawer = new MTS.Drawer({ title: 'Confirm action', content: '<p>Are you sure you want to proceed?</p>', // Static — only closes via code / Estático — solo cierra via código static: true, onClose: () => console.log('closed'), }); // API drawer.show() drawer.hide() drawer.toggle() drawer.setTitle('Updated title') drawer.setContent('<p>New content</p>') drawer.destroy()
