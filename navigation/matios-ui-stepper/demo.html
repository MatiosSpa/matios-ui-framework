MTS.Stepper

Wizard (with panels) and progress (visual indicator) — horizontal/vertical, clickable, status management.

1 — mode:wizard — flujo multi-paso / Multi-step flow
— navega los pasos —
<div id="my-stepper"></div> <script> const stepper = new MTS.Stepper('#my-stepper', { mode: 'wizard', steps: [ { id: 's1', label: 'Personal data', content: '<div id="form-s1"></div>' }, { id: 's2', label: 'Security', content: '<div id="form-s2"></div>' }, { id: 's3', label: 'Confirm', content: '<div id="summary"></div>' }, ], // Fires when step changes / Se dispara al cambiar de paso onChange: (e) => console.log(e.detail.index, e.detail.direction), // Fires when last step reached / Se dispara al llegar al último paso onComplete: () => console.log('complete!'), }); stepper.next() stepper.prev() stepper.goTo(2) </script>
const stepper = new MTS.Stepper('#my-stepper', { mode: 'wizard', steps: [ { id: 's1', label: 'Personal data', description: 'Name and contact', content: '<div class="step-panel"><h3>Step 1</h3><p>Fill in your personal info.</p></div>', }, { id: 's2', label: 'Security', content: '<div class="step-panel"><h3>Step 2</h3><p>Create a password.</p></div>', }, { id: 's3', label: 'Confirm', content: '<div class="step-panel"><h3>Step 3</h3><p>Review and submit.</p></div>', }, ], // Fires when step changes / Se dispara al cambiar de paso onChange: (e) => { console.log(e.detail.index); // → new step index console.log(e.detail.direction); // → 'next' | 'prev' | 'jump' }, // Fires on last step / Se dispara en el último paso onComplete: () => console.log('All steps done!'), });

3 — Clickable + setStepStatus()
— usa los botones —
<div id="my-stepper"></div> <script> const s = new MTS.Stepper('#my-stepper', { mode: 'progress', variant: 'default', clickable: true, steps: [...], onStepClick: (e) => console.log('clicked:', e.detail.index), onStatusChange: (e) => console.log('status:', e.detail.status), }); s.setStepStatus(1, 'error') // mark error / marcar error s.setStepStatus(1, 'pending') // reset / resetear s.goTo(2) // jump / saltar </script>
const s = new MTS.Stepper('#my-stepper', { mode: 'progress', variant: 'default', // Allow clicking completed steps / Permitir click en pasos completados clickable: true, steps: [ { id:'a', label:'Validate', description:'Check data' }, { id:'b', label:'Process', description:'Run tasks' }, { id:'c', label:'Review', description:'Verify results' }, { id:'d', label:'Complete', description:'Done' }, ], // Fires on step click / Se dispara al hacer click en un paso onStepClick: (e) => console.log('clicked:', e.detail.index), // Fires on status change / Se dispara al cambiar el estado onStatusChange: (e) => console.log('status:', e.detail.status), }); s.setStepStatus(1, 'error') // mark step 1 as error / marcar paso 1 como error s.setStepStatus(1, 'pending') // reset to pending / resetear a pendiente s.goTo(2) // jump to step 2 / saltar al paso 2
