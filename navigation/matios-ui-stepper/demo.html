MTS.Stepper

Flujo paso a paso — mode:wizard (con paneles) y mode:progress (indicador visual).

1 — mode:wizard — formulario multi-paso con componentes MTS

💡 Los componentes MTS se montan lazy — solo cuando llegas al paso. Prueba navegar hacia atrás y adelante.

— navega entre pasos —
const stepper = new MTS.Stepper('#el', {
  mode: 'wizard',
  steps: [
    { id:'datos',    label:'Datos personales', description:'Nombre y contacto',
      content: '<div class="wizard-panel"><div id="wf-nombre"></div></div>' },

    { id:'seguridad', label:'Seguridad', description:'Contraseña',
      // Función lazy — se ejecuta solo cuando llegas al paso
      content: () => buildPanelSeguridad() },

    { id:'confirm',   label:'Confirmación',
      content: () => buildPanelConfirmacion() },
  ],
  onChange: (e) => {
    // DOM ya visible — montar componentes MTS aquí
    if (e.detail.index === 0) {
      new MTS.Input('#wf-nombre', { label: 'Nombre', placeholder: 'Juan Pérez' })
    }
  },
  onComplete: () => console.log('¡Formulario completado!'),
})

3 — mode:progress variant:default — checkout con navegación
— navega entre pasos —
new MTS.Stepper('#el', {
  mode:      'progress',
  variant:   'default',   // indicador + label + descripción
  clickable:  true,
  steps: [
    { id:'cart',    label:'Carrito',    description:'Revisa tus productos' },
    { id:'ship',    label:'Envío',      description:'Dirección de entrega'  },
    { id:'payment', label:'Pago',       description:'Método de pago'        },
    { id:'confirm', label:'Confirmado'                                       },
  ],
  onChange:   (e) => console.log('paso:', e.detail.index, e.detail.direction),
  onComplete: (e) => console.log('¡completado!'),
})

6 — setStepStatus() — estados error y complete
— usa los botones —
const s = new MTS.Stepper('#el', { mode:'progress', active:2, steps:[...] })
s.setStepStatus(2, 'error')    // marcar como error
s.setStepStatus(2, 'pending')  // volver a pendiente
s.goTo(0, 'jump')
// 'complete' y 'active' se gestionan automáticamente al navegar
7 — Eventos: onChange, onComplete, onStepClick, onStatusChange
— navega para ver los eventos —
const s = new MTS.Stepper('#el', {
  mode: 'progress', clickable: true,
  steps: [...],

  onChange: (e) => {
    // e.detail.index     → índice nuevo
    // e.detail.prev      → índice anterior
    // e.detail.step      → objeto del paso
    // e.detail.direction → 'next'|'prev'|'jump'
  },
  onComplete:     (e) => { /* último paso alcanzado */ },
  onStepClick:    (e) => { /* click manual en paso */ },
  onStatusChange: (e) => { /* setStepStatus() llamado */ },
})
