MTS.Dropdown

Dropdown menu — groups, icons, shortcuts, dividers, submenus and hover mode.

1 — Básico con eventos / Basic with events
— selecciona un ítem —
<button id="btn-actions">Actions ▾</button> <script> new MTS.Dropdown('#btn-actions', { items: [ { id: 'edit', label: 'Edit' }, { id: 'copy', label: 'Duplicate' }, { divider: true }, { id: 'delete', label: 'Delete', disabled: true }, ], // Fires when an item is selected / Se dispara al seleccionar un ítem onSelect: (e) => console.log(e.detail.id, e.detail.item), onOpen: () => console.log('opened'), onClose: () => console.log('closed'), }); </script>
new MTS.Dropdown('#btn-actions', { items: [ { id: 'edit', label: 'Edit' }, { id: 'copy', label: 'Duplicate' }, { divider: true }, // separator line / línea separadora { id: 'delete', label: 'Delete', disabled: true }, ], // Fires when an item is selected / Se dispara al seleccionar un ítem onSelect: (e) => { console.log(e.detail.id); // → 'edit' console.log(e.detail.item); // → { id, label, ... } }, onOpen: () => console.log('opened'), onClose: () => console.log('closed'), });

4 — Submenús anidados / Nested submenus
— selecciona un ítem —
<button id="btn-edit">Edit ▾</button> <script> new MTS.Dropdown('#btn-edit', { items: [ { id: 'cut', label: 'Cut', shortcut: '⌘X' }, { id: 'copy', label: 'Copy', shortcut: '⌘C' }, { id: 'paste', label: 'Paste', shortcut: '⌘V' }, { divider: true }, { id: 'export', label: 'Export as', items: [ { id: 'pdf', label: 'PDF' }, { id: 'csv', label: 'CSV' }, { id: 'xlsx', label: 'Excel' }, ]}, ], onSelect: (e) => console.log(e.detail.id), }); </script>
// Nested submenu / Submenú anidado (items inside items) new MTS.Dropdown('#btn-edit', { items: [ { id: 'cut', label: 'Cut', shortcut: '⌘X' }, { id: 'copy', label: 'Copy', shortcut: '⌘C' }, { id: 'paste', label: 'Paste', shortcut: '⌘V' }, { divider: true }, // items[] creates a submenu / items[] crea un submenú { id: 'export', label: 'Export as', items: [ { id: 'pdf', label: 'PDF' }, { id: 'csv', label: 'CSV' }, { id: 'xlsx', label: 'Excel (.xlsx)' }, ]}, ], onSelect: (e) => console.log(e.detail.id), }); // Hover trigger / Trigger hover new MTS.Dropdown('#btn-hover', { trigger: 'hover', // opens on mouseenter / abre en mouseenter items: [ { id: 'a', label: 'Option A' }, { id: 'b', label: 'Option B' }, ], });
