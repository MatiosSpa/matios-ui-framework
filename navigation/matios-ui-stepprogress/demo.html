MTS.StepProgress

Step progress indicator — checkout, onboarding and pipeline style. Default, compact and dots variants.

1 — Default — checkout con navegación / Checkout with navigation
— navega los pasos —
<div id="checkout-progress"></div> <script> const sp = new MTS.StepProgress('#checkout-progress', { variant: 'default', active: 1, steps: [ { id: 'cart', label: 'Cart', description: 'Review products' }, { id: 'ship', label: 'Shipping', description: 'Delivery address' }, { id: 'payment', label: 'Payment', description: 'Payment method' }, { id: 'confirm', label: 'Confirmed' }, ], // Fires when active step changes / Se dispara al cambiar el paso activo onChange: (e) => { console.log(e.detail.index); // → 2 console.log(e.detail.step); // → { id, label, description } }, }); sp.next() // advance / avanzar sp.prev() // back / retroceder sp.goTo(2) // jump / saltar </script>
const sp = new MTS.StepProgress('#my-progress', { // Visual variant / Variante visual variant: 'default', // Initially active step / Paso activo inicial active: 1, steps: [ { id: 'cart', label: 'Cart', description: 'Review your products' }, { id: 'ship', label: 'Shipping', description: 'Delivery address' }, { id: 'payment', label: 'Payment', description: 'Payment method' }, { id: 'confirm', label: 'Confirmed' }, ], // Fires when active step changes / Se dispara al cambiar el paso activo onChange: (e) => { console.log(e.detail.index); // → new step index console.log(e.detail.step); // → { id, label, description } }, }); // Navigate / Navegar sp.next() // advance one step / avanzar un paso sp.prev() // go back / retroceder sp.goTo(2) // jump to index / saltar al índice

4 — setStepStatus() — error y pending
— usa los botones —
<div id="my-progress"></div> <script> const sp = new MTS.StepProgress('#my-progress', { variant: 'default', active: 2, steps: [...], }); sp.setStepStatus(1, 'error') // mark step 1 as error sp.setStepStatus(1, 'pending') // reset to pending sp.getActive() // → { index: 2, step: { id, label } } </script>
