MTS.Tabs

Underline, pill and card variants — horizontal and vertical layout — lazy rendering.

1 — Underline (default)
— cambia de pestaña —
<div id="my-tabs"></div> <script> new MTS.Tabs('#my-tabs', { variant: 'underline', tabs: [ { id: 'overview', label: 'Overview', content: '<p>Overview content</p>' }, { id: 'details', label: 'Details', content: '<p>Details content</p>' }, { id: 'history', label: 'History', content: '<p>History content</p>' }, ], // Fires when active tab changes / Se dispara al cambiar la pestaña onChange: (e) => console.log(e.detail.id), }); </script>
new MTS.Tabs('#my-tabs', { // Visual variant: 'underline' | 'pill' | 'card' variant: 'underline', // Initially active tab / Pestaña activa inicial active: 'overview', tabs: [ { id: 'overview', label: 'Overview', content: '<p>Overview content</p>' }, { id: 'details', label: 'Details', content: '<p>Details content</p>' }, { id: 'history', label: 'History', content: '<p>History content</p>', disabled: true }, ], // Fires when active tab changes / Se dispara al cambiar la pestaña activa onChange: (e) => { console.log(e.detail.id); // → 'details' console.log(e.detail.tab); // → { id, label, content } }, });

6 — API — setActive() programático
— usa los botones —
<div id="my-tabs"></div> <script> const tabs = new MTS.Tabs('#my-tabs', { tabs: [...] }); tabs.setActive('tab-id') tabs.addTab({ id: 'new', label: 'New', content: '...' }) tabs.removeTab('tab-id') </script>
const tabs = new MTS.Tabs('#my-tabs', { tabs: [ { id: 'alpha', label: 'Alpha', content: '<p>Alpha</p>' }, { id: 'beta', label: 'Beta', content: '<p>Beta</p>' }, { id: 'gamma', label: 'Gamma', content: '<p>Gamma</p>' }, ], onChange: (e) => console.log('active:', e.detail.id), }); // Activate tab programmatically / Activar pestaña programáticamente tabs.setActive('beta') // Add a new tab / Agregar una nueva pestaña tabs.addTab({ id: 'delta', label: 'Delta', content: '<p>Delta</p>' }) // Remove a tab / Eliminar una pestaña tabs.removeTab('delta')
