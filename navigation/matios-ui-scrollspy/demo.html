MTS.ScrollSpy

Highlights the active nav link as the user scrolls through sections.

1 — Demo interactivo — scroll dentro del panel / Interactive — scroll inside the panel
Introducción Instalación Uso básico API Eventos

Introducción

MTS.ScrollSpy resalta automáticamente el enlace de navegación que corresponde a la sección visible mientras el usuario hace scroll. Ideal para páginas de documentación y landing pages.

Instalación

Incluye el CSS base y el script del componente. No requiere dependencias externas. Funciona con cualquier estructura HTML que tenga secciones con IDs y una navegación con enlaces href.

Uso básico

Instancia MTS.ScrollSpy con el selector de las secciones y el contenedor de navegación. El componente detecta automáticamente el scroll y aplica la clase activa al link correspondiente.

API

La API es simple: instancia el componente con las opciones deseadas y llama destroy() cuando ya no lo necesites para liberar el event listener del scroll.

Eventos

El componente dispara onChange cuando la sección activa cambia, proporcionando el ID, el elemento de sección y el link correspondiente en el navegador.

<!-- Navigation / Navegación --> <nav id="page-nav"> <a href="#intro">Introduction</a> <a href="#features">Features</a> <a href="#api">API</a> </nav> <!-- Content sections / Secciones de contenido --> <section id="intro">...</section> <section id="features">...</section> <section id="api">...</section> <script> new MTS.ScrollSpy({ sections: 'section[id]', nav: '#page-nav', activeClass: 'active', offset: 80, // Fires when active section changes / Se dispara al cambiar la sección activa onChange: (e) => { console.log(e.detail.id); // → 'features' console.log(e.detail.section); // → HTMLElement console.log(e.detail.link); // → <a> element }, }); </script>
const spy = new MTS.ScrollSpy({ // CSS selector for sections / Selector CSS de las secciones sections: '.spy-section', // Nav container / Contenedor de navegación nav: '#spy-nav', // Link attribute with section ID / Atributo del link con el ID de sección linkAttr: 'href', // Offset from top (e.g. fixed header height) / Offset desde el top offset: 0, // CSS class for the active link / Clase CSS para el link activo activeClass: 'active', // Fires when active section changes / Se dispara al cambiar la sección activa onChange: (e) => { console.log(e.detail.id); // → 'sec-install' console.log(e.detail.section); // → HTMLElement (the section) console.log(e.detail.link); // → HTMLElement (the nav link) | null }, });
