MTS.Breadcrumb

Ruta de navegación con separadores, íconos y colapso automático.

1 — Básico con onClick
— haz click en un item —
new MTS.Breadcrumb('#el', {
  separator: '/',
  items: [
    { label:'Inicio',      onClick:() => console.log('inicio') },
    { label:'Proyectos',   onClick:() => console.log('proyectos') },
    { label:'Matios UI',   onClick:() => console.log('matios') },
    { label:'Navigation' },  // último — no clickeable
  ],
  onClick: (e) => console.log('click:', e.detail.item.label),
})
2 — Con separador personalizado
// Separador custom — cualquier HTML
new MTS.Breadcrumb('#el', { separator:'›', items:[...] })
new MTS.Breadcrumb('#el', { separator:'→', items:[...] })
3 — Con íconos
new MTS.Breadcrumb('#el', {
  items: [
    { label:'Inicio',      icon:MTS.Icon.get('home'),     onClick:() => {} },
    { label:'Clientes',    icon:MTS.Icon.get('users'),    onClick:() => {} },
    { label:'Acme Corp',   icon:MTS.Icon.get('briefcase'),onClick:() => {} },
    { label:'Contrato #42' },
  ],
})
4 — Colapso con maxItems
// Si hay más items que maxItems, colapsa los del medio en "..."
new MTS.Breadcrumb('#el', {
  maxItems: 4,
  items: [/* 7 items */],
})
