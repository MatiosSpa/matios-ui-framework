MTS.Accordion

Expandable sections — single or multiple open, flush mode, icons, programmatic control.

1 — Básico — un panel abierto / Single open (default)
— abre o cierra un panel —
<div id="my-accordion"></div> <script> new MTS.Accordion('#my-accordion', { items: [ { id: 'q1', title: 'What is Matios UI?', content: '<p>A zero-dependency library.</p>', open: true }, { id: 'q2', title: 'How do I install it?', content: '<p>Add CSS and JS files.</p>' }, { id: 'q3', title: 'Is it free?', content: '<p>Yes, MIT licensed.</p>' }, ], // Fires when a panel opens / Se dispara al abrir un panel onOpen: (e) => console.log('opened:', e.detail.id), // Fires when a panel closes / Se dispara al cerrar un panel onClose: (e) => console.log('closed:', e.detail.id), }); </script>

4 — API — control programático
— usa los botones —
<div id="my-accordion"></div> <script> const acc = new MTS.Accordion('#my-accordion', { multiple: true, items: [...], }); acc.open('p1') acc.close('p1') acc.toggle('p2') acc.openAll() acc.closeAll() acc.isOpen('p1') // → boolean </script>
const acc = new MTS.Accordion('#my-accordion', { multiple: true, items: [ { id: 'p1', title: 'Panel 1', content: '...' }, { id: 'p2', title: 'Panel 2', content: '...' }, { id: 'p3', title: 'Panel 3', content: '...' }, ], onOpen: (e) => console.log('opened:', e.detail.id), onClose: (e) => console.log('closed:', e.detail.id), }); acc.open('p1') // open panel / abrir panel acc.close('p1') // close panel / cerrar panel acc.toggle('p2') // toggle panel / alternar panel acc.openAll() // open all / abrir todos acc.closeAll() // close all / cerrar todos acc.isOpen('p1') // → true | false
