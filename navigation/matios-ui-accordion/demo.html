MTS.Accordion

Secciones expandibles — individual o múltiple, con íconos y eventos.

1 — Básico — uno abierto a la vez
— expande una sección —
new MTS.Accordion('#el', {
  multiple: false,   // solo uno abierto a la vez
  items: [
    { id:'a1', title:'¿Qué es?',         content:'
...
', open:true },
    { id:'a2', title:'¿Cómo instalar?',  content:'
...
' },
    { id:'a3', title:'Sección disabled', content:'
...
', disabled:true },
  ],
  onOpen:  (e) => console.log('abierto:', e.detail.id),
  onClose: (e) => console.log('cerrado:', e.detail.id),
})
2 — Multiple + Flush (sin bordes card)
new MTS.Accordion('#el', {
  multiple: true,   // varios abiertos simultáneamente
  flush:    true,   // sin bordes laterales — solo separadores
  items: [...],
})
3 — Con íconos
new MTS.Accordion('#el', {
  items: [
    { id:'cfg', title:'Configuración', icon:MTS.Icon.get('settings'), content:'...' },
    { id:'usr', title:'Usuarios',      icon:MTS.Icon.get('users'),    content:'...' },
    { id:'sec', title:'Seguridad',     icon:MTS.Icon.get('shield'),   content:'...' },
  ],
})
4 — API — abrir/cerrar programáticamente
const acc = new MTS.Accordion('#el', { multiple:true, items:[...] })
acc.open('mi-id')
acc.close('mi-id')
acc.toggle('mi-id')
acc.openAll()
acc.closeAll()
acc.isOpen('mi-id')  // → boolean
