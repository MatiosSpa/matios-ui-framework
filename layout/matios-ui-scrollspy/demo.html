Instalación

Incluye el CSS y JS del componente en tu proyecto. No requiere dependencias adicionales.

Uso básico

Inicializa el componente con las secciones y el contenedor de navegación que quieres espiar.

API

El componente expone métodos para destruir el observer cuando ya no se necesita el seguimiento.

Eventos

Escucha el evento onChange para reaccionar cuando cambia la sección activa en el scroll.

— haz scroll en el panel de arriba —
new MTS.ScrollSpy({
  sections:    '#intro, #instalacion, #uso, #api',
  nav:         '#mi-nav',
  offset:       80,
  onChange: ({ id, section, link }) => {
    console.log('sección activa:', id)
  },
})
