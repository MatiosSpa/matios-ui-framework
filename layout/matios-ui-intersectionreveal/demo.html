MTS.IntersectionReveal

Anima elementos al entrar al viewport. Reemplaza AOS/ScrollReveal.

1 — Diferentes animaciones
⬆️
fade-up
Desde abajo
⬇️
fade-down
Desde arriba
➡️
fade-left
Desde derecha
⬅️
fade-right
Desde izquierda
🔍
zoom
Zoom in
🔄
flip
Flip vertical
// Animar todos los elementos .card al entrar al viewport
new MTS.IntersectionReveal('.card', {
  animation: 'fade-up',
  duration:   600,
  stagger:    80,   // delay entre cada elemento
  threshold:  0.15,
  once:       true,
})

// Diferentes animaciones por grupo
new MTS.IntersectionReveal('.titles',   { animation:'fade-down' })
new MTS.IntersectionReveal('.sidebars', { animation:'fade-left' })
new MTS.IntersectionReveal('.cards',    { animation:'zoom', stagger:100 })
