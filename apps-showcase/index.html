Grupos del showcase

Hoy quedan visibles solo Autenticacion, Onboarding, Usuarios, Perfiles, Roles, Workflows y Security.

Autenticacion

Familia inicial del showcase. Contiene el acceso unificado listo y el resto del flujo como placeholders controlados.

Onboarding

Inicio del flujo de registro y puesta en marcha. El grupo parte con variantes de signup para productos uniempresa y multiempresa.

Usuarios

Gestion operativa de cuentas internas: listado, alta, edicion, detalle y cambio de clave desde una superficie administrativa simple.

Perfiles

Perfiles por modulo con permisos finos chequeables. Sirven como base para que luego los roles agrupen un perfil por modulo.

Roles

Roles como agrupacion de perfiles por modulo. Cada modulo admite un unico perfil seleccionado dentro del rol.

Support

Flujos base para helpdesk operativo: bandeja de triage, detalle del caso y siguientes estados del ciclo de soporte.

Productivity

Flujos para gestionar trabajo y tiempo: tablero de tareas, planificacion semanal y siguientes vistas operativas del equipo.

Documents

Vistas ligeras para archivos y contenido operativo. El foco es dejar experiencias copiables que no dependan de tablas densas ni gestores documentales complejos.

Search

Busqueda transversal, refinamiento y discovery para productos que necesitan encontrar personas, contenido y settings sin depender de vistas aisladas.

Account

Pantallas para perfil personal, seguridad y preferencias de cuenta. El foco es dejar vistas copiables para que un producto real pueda arrancar rapido sin inventar UI nueva.

Settings

Ajustes de workspace y politicas compartidas. El objetivo es dejar vistas reutilizables para productos reales que necesitan configuracion sin depender de tablas ni dashboards.

Admin

Gestion operativa de miembros, invitaciones y acceso inicial al workspace. El foco es dejar vistas reales para productos B2B y plataformas internas.

Billing

Plan, cobros y medios de pago para productos SaaS. Son pantallas listas para copiar en contextos reales sin depender de dashboards.

Integrations

Catalogo y configuracion de conexiones externas para productos B2B. Son vistas utiles para catalogar providers, estado de sync y acciones de soporte sin caer en mockups.

Security

Sesiones, auditoria y trazabilidad para productos que necesitan visibilidad real sobre acceso, actividad sensible y control operativo.

Developers

Herramientas para integradores y equipos tecnicos: credenciales, control de acceso y puntos de contacto con APIs o automatizaciones.

Workflows

Bandejas, tareas y definiciones de workflow para permisos, documentos, presupuestos y cualquier otro requerimiento que necesite etapas, routing y trazabilidad.

System

Estados vacios, mantenimiento y errores operativos listos para copiar en productos reales. Son pantallas base que suelen quedar para el final y aqui ya quedan resueltas.

Notifications

Centro de alertas, actividad reciente y seguimiento transversal del producto. El foco es dejar patrones copiables para avisos y feed sin depender de tablas.
