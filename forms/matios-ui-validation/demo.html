MTS.Validate

Validación de formularios — 15+ reglas, integración automática con MTS.Input.

1 — Formulario completo con todas las reglas
— completa y haz click en Validar —
const v = new MTS.Validate('#mi-form',{
  validateOnBlur:true,
  rules:{
    nombre:   {required:true, minLength:3},
    email:    {required:true, email:true},
    rut:      {required:true, rut:true},      // validación RUT chileno
    edad:     {required:true, min:18, max:99},
    password: {required:true, minLength:8, pattern:/(?=.*\d)/},
    password2:{required:true, equalTo:'[name="password"]'},
    terminos: {required:true},
  },
  onValid:   (data)   => enviar(data),
  onInvalid: (errors) => console.log(errors),
})
v.validate()
v.setError('email','Email ya registrado')  // error del servidor
v.clearErrors()
v.getData()
