MTS.Validate

Form validation — auto-integrates with MTS.Input, 20+ rules, custom messages, server-side errors.

1 — Formulario completo / Full form
— completa y envía el formulario —
<form id="my-form"> <div id="field-name"></div> <div id="field-email"></div> <button type="submit" class="mts-btn mts-btn--primary">Submit</button> </form> <script> // name: must match the key in rules / name: debe coincidir con la clave en rules new MTS.Input('#field-name', { name:'name', label: 'Name', rules: { required: true, minLength: 3 } }); new MTS.Input('#field-email', { name:'email', label: 'Email', type: 'email', rules: { required: true, email: true } }); new MTS.Validate('#my-form', { rules: { name: { required: true, minLength: 3 }, email: { required: true, email: true }, }, // Fires when form is valid / Se dispara cuando el formulario es válido onValid: (data) => console.log('Valid:', data), // Fires when form has errors / Se dispara cuando hay errores onInvalid: (errors) => console.log('Errors:', errors), }); </script>
// Step 1: Create MTS.Input fields with rules // Paso 1: Crear campos MTS.Input con reglas // name: must match the key in rules / name: debe coincidir con la clave en rules new MTS.Input('#v-name', { name:'name', label: 'Full name', placeholder: 'John Doe', rules: { required: true, minLength: 3 } }); new MTS.Input('#v-email', { name:'email', label: 'Email', placeholder: 'user@example.com', rules: { required: true, email: true }, type: 'email' }); new MTS.Input('#v-pass', { name:'password', label: 'Password', placeholder: 'Min 8 characters', rules: { required: true, minLength: 8 }, type: 'password' }); new MTS.Input('#v-pass2', { name:'password2', label: 'Confirm password', placeholder: 'Repeat password', rules: { required: true }, type: 'password' }); // Step 2: Attach MTS.Validate to the form // Paso 2: Vincular MTS.Validate al formulario new MTS.Validate('#form-full', { rules: { name: { required: true, minLength: 3 }, email: { required: true, email: true }, password: { required: true, minLength: 8 }, password2: { required: true }, }, // Custom messages / Mensajes personalizados messages: { name: { required: 'Name is required', minLength: 'At least 3 characters' }, email: { email: 'Enter a valid email' }, }, validateOnBlur: true, // Fires when all fields are valid / Se dispara cuando todo es válido onValid: (data) => console.log('Form data:', data), // Fires when there are errors / Se dispara cuando hay errores onInvalid: (errors) => console.log('Errors:', errors), });
2 — Reglas avanzadas / Advanced rules
— completa y envía el formulario —
<form id="my-form"> <div id="field-rut"></div> <div id="field-age"></div> <div id="field-url"></div> <div id="field-custom"></div> <button type="submit">Submit</button> </form> <script> new MTS.Input('#field-rut', { label:'RUT', rules:{ required:true, rut:true } }); new MTS.Input('#field-age', { label:'Age', type:'number', rules:{ required:true, min:18, max:99 } }); new MTS.Input('#field-custom', { label:'Username', rules:{ custom: (val) => val !== 'admin' || 'Username not allowed' } }); </script>
// Chilean RUT / RUT chileno new MTS.Input('#field-rut', { label: 'RUT', placeholder: '12.345.678-9', rules: { required: true, rut: true }, }); // Numeric range / Rango numérico new MTS.Input('#field-age', { label: 'Age', type: 'number', rules: { required: true, min: 18, max: 99 }, }); // URL validation / Validación URL new MTS.Input('#field-url', { label: 'Website', placeholder: 'https://...', rules: { url: true }, }); // Custom validation / Validación personalizada new MTS.Input('#field-custom', { label: 'Username', rules: { required: true, // Return true if valid, or error string / Retorna true si válido o string de error custom: (val) => val !== 'admin' ? true : 'Username not allowed', }, });
3 — API — errores del servidor / Server-side errors
— usa los botones —
<form id="my-form"> <div id="field-email"></div> <button type="submit">Register</button> </form> <script> new MTS.Input('#field-email', { label:'Email', type:'email', rules:{ required:true, email:true } }); const v = new MTS.Validate('#my-form', { rules: { email: { required:true, email:true } }, onValid: async (data) => { const res = await register(data); if (res.error) v.setError('email', 'Email already exists'); }, }); v.isValid() // → boolean v.getData() // → { email: '...' } v.getErrors() // → { email: 'message' } v.clearErrors() // clear all / limpiar todos v.setError('email', 'Server error') // server-side error </script>
new MTS.Input('#field-email', { label: 'Email address', type: 'email', rules: { required: true, email: true }, }); const v = new MTS.Validate('#form-api', { rules: { email: { required: true, email: true } }, // Fires when valid / Se dispara cuando es válido onValid: async (data) => { // Simulate server error / Simular error del servidor v.setError('email', 'Email already registered'); }, onInvalid: (errors) => console.log(errors), }); // API methods / Métodos de la API v.validate() // → boolean v.isValid() // → boolean v.getData() // → { fieldName: value } v.getErrors() // → { fieldName: 'message' } v.clearErrors() v.setError('email', 'Already exists') // server error / error del servidor
