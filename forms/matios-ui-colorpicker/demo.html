MTS.ColorPicker

Standalone color picker — HSL sliders, preset palette, hex/rgb/hsl output.

1 — Trigger (popup) — tamaños / sizes
— selecciona un color —
<div id="picker-brand" data-value="#7c3aed" data-label="Brand color" data-format="hex"> </div> <script> new MTS.ColorPicker('#picker-brand', { // Fires when color changes / Se dispara al cambiar el color onChange: ({ hex, value }) => { console.log(hex); // → '#7c3aed' (always hex) console.log(value); // → formatted value }, }); </script>
// Small / Pequeño new MTS.ColorPicker('#cp-sm', { value: '#f87171', label: 'Color (sm)', size: 'sm', format: 'hex', // Fires on color change / Se dispara al cambiar el color onChange: ({ hex, value }) => console.log(hex), }); // Medium (default) / Mediano new MTS.ColorPicker('#cp-md', { value: '#4f8eff', label: 'Color (md)', size: 'md', onChange: ({ hex }) => console.log(hex), }); // Large / Grande new MTS.ColorPicker('#cp-lg', { value: '#34d399', label: 'Color (lg)', size: 'lg', onChange: ({ hex }) => console.log(hex), });
2 — Inline (siempre visible / always visible)
— mueve los sliders —
<!-- inline: true — no trigger button / sin botón trigger --> <div id="picker-inline" data-inline data-value="#34d399"></div> <script> new MTS.ColorPicker('#picker-inline', { onChange: ({ hex }) => { document.getElementById('preview').style.background = hex; }, }); </script>
new MTS.ColorPicker('#picker-inline', { // Always visible, no trigger / Siempre visible, sin trigger inline: true, value: '#34d399', format: 'hex', onChange: ({ hex, value }) => { console.log(hex, value); }, });
3 — Formatos hex · rgb · hsl + API
— usa los botones —
<div id="picker-brand" data-value="#4f8eff" data-format="hex"></div> <script> const cp = new MTS.ColorPicker('#picker-brand', { onChange: ({ hex, value }) => console.log(hex, value), }); cp.getValue() // respects format / respeta format cp.getHex() // always hex / siempre hex cp.setValue('#00ff00') cp.setFormat('rgb') cp.open() / cp.close() </script>
// Format: 'hex' | 'rgb' | 'hsl' new MTS.ColorPicker('#cp-hex', { value:'#4f8eff', label:'HEX', format:'hex', onChange: ({value}) => console.log(value) }); new MTS.ColorPicker('#cp-rgb', { value:'#4f8eff', label:'RGB', format:'rgb', onChange: ({value}) => console.log(value) }); new MTS.ColorPicker('#cp-hsl', { value:'#4f8eff', label:'HSL', format:'hsl', onChange: ({value}) => console.log(value) }); const cp = new MTS.ColorPicker('#my-picker', { value: '#4f8eff', format: 'hex' }); // Get value respecting format / Obtener valor respetando formato cp.getValue() // → '#4f8eff' | 'rgb(79,142,255)' | 'hsl(218,100%,66%)' // Always get hex / Siempre obtener hex cp.getHex() // → '#4f8eff' // Set color / Establecer color cp.setValue('#f87171') // Change output format / Cambiar formato de salida cp.setFormat('rgb') // Open / close / Abrir / cerrar cp.open() cp.close()
4 — Sin sliders · sin presets · disabled
<!-- Preset only / Solo presets --> <div id="picker-presets-only" data-value="#f87171"></div> <script> new MTS.ColorPicker('#picker-presets-only', { showSliders: false, showInput: false, }); </script> <!-- Sliders only / Solo sliders --> <div id="picker-sliders-only" data-value="#4f8eff"></div> <script> new MTS.ColorPicker('#picker-sliders-only', { showPresets: false, }); </script>
// Preset palette only / Solo paleta de presets new MTS.ColorPicker('#cp-presets', { showSliders: false, showInput: false, value: '#f87171', label: 'Preset only', }); // Sliders only / Solo sliders new MTS.ColorPicker('#cp-sliders', { showPresets: false, value: '#4f8eff', label: 'Sliders only', }); // Disabled / Deshabilitado new MTS.ColorPicker('#cp-disabled', { value: '#94a3b8', label: 'Disabled', disabled: true, });
