MTS.Slider

Range input — simple, doble (rango), con formato personalizado, con step y disabled.

1 — Slider simple
— mueve los sliders —
<!-- El slider requiere JavaScript para el fill dinámico. Usa el componente MTS.Slider para instanciarlo. --> <div class="mts-slider-wrap"> <div class="mts-slider__header"> <span class="mts-label">Volumen</span> <span class="mts-slider__value">65</span> </div> <div class="mts-slider__track"> <div class="mts-slider__fill" style="left:0%;width:65%"></div> <input type="range" class="mts-slider__input" min="0" max="100" value="65"> </div> </div>
// Básico const sl = new MTS.Slider('#el', { label: 'Volumen', min: 0, max: 100, value: 65, showValue: true, onChange: (e) => console.log(e.detail.value), }); // Con formato personalizado const slP = new MTS.Slider('#el', { label: 'Brillo', min: 0, max: 100, value: 80, showValue: true, labelFormat: (v) => v + '%', }); // Con step const slS = new MTS.Slider('#el', { label: 'Temperatura', min: 16, max: 30, step: 0.5, value: 22, showValue: true, labelFormat: (v) => v + '°C', }); // API sl.getValue() // → number sl.setValue(50)
2 — Rango doble (range)
— mueve los sliders de rango —
<!-- El rango doble requiere dos inputs superpuestos. Se recomienda usar MTS.Slider con range: true --> <div class="mts-slider-wrap"> <div class="mts-slider__header"> <span class="mts-label">Rango de edad</span> <span class="mts-slider__value">25 – 45</span> </div> <div class="mts-slider__track"> <div class="mts-slider__fill" style="left:25%;width:20%"></div> <input type="range" class="mts-slider__input" min="0" max="100" value="25"> <input type="range" class="mts-slider__input" min="0" max="100" value="45"> </div> </div>
// Rango de edad const slR = new MTS.Slider('#el', { range: true, label: 'Rango de edad', min: 0, max: 100, value: [25, 45], showValue: true, onChange: (e) => console.log(e.detail.value), // → [25, 45] }); // Rango de precio con formato const slP = new MTS.Slider('#el', { range: true, label: 'Precio', min: 0, max: 1000, step: 10, value: [200, 700], showValue: true, labelFormat: ([a, b]) => '$' + a + ' – $' + b, }); // API slR.getValue() // → [25, 45] slR.setValue([30, 60])
