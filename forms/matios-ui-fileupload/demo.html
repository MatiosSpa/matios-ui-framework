MTS.FileUpload

Upload con drag & drop, preview de imágenes y validación de tipo y tamaño.

1 — Imágenes con preview
— arrastra o selecciona imágenes —
new MTS.FileUpload('#el',{accept:'image/*',multiple:true,maxSize:5,maxFiles:8,preview:true,
  hint:'PNG, JPG, GIF hasta 5MB',onChange:(files)=>console.log(files.map(f=>f.name))})
2 — Documento único
— arrastra un documento —
new MTS.FileUpload('#el',{accept:'.pdf,.docx,.xlsx',multiple:false,maxSize:20,preview:false,
  hint:'PDF, Word, Excel hasta 20MB',onChange:(files)=>console.log(files[0]?.name)})
3 — Callbacks onAdd / onRemove / onError
— arrastra o selecciona archivos —
new MTS.FileUpload('#zona', {
  accept:   'image/*,.pdf',
  multiple: true,
  maxSize:  5,
  onChange:  (files) => console.log('total:', files.length),
  onAdd:     (file)  => console.log('agregado:', file.name),
  onRemove:  (file)  => console.log('eliminado:', file.name),
  onError:   (errs)  => console.error(errs),
})
