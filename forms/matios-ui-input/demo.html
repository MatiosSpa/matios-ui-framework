MTS.Input

Input de texto, email, password, number y textarea — con validación, íconos, clearable y contador.

1 — Tipos de input
<!-- HTML declarativo — el componente lee los data-* al instanciar --> <div id="inp-text" data-type="text" data-label="Nombre" data-placeholder="Ingresa tu nombre" data-hint="Mínimo 3 caracteres"> </div> <div id="inp-email" data-type="email" data-label="Correo electrónico" data-placeholder="usuario@ejemplo.com" data-required> </div> <div id="inp-password" data-type="password" data-label="Contraseña" data-placeholder="••••••••" data-show-password> </div> <div id="inp-number" data-type="number" data-label="Cantidad" data-placeholder="0"> </div> <script> new MTS.Input('#inp-text'); new MTS.Input('#inp-email'); new MTS.Input('#inp-password'); new MTS.Input('#inp-number'); </script>
// Crear el componente 100% desde JavaScript — sin HTML previo const inputTexto = new MTS.Input('#inp-text', { type: 'text', label: 'Nombre', placeholder: 'Ingresa tu nombre', hint: 'Mínimo 3 caracteres', }); const inputEmail = new MTS.Input('#inp-email', { type: 'email', label: 'Correo electrónico', placeholder: 'usuario@ejemplo.com', required: true, }); const inputPassword = new MTS.Input('#inp-password', { type: 'password', label: 'Contraseña', placeholder: '••••••••', showPassword: true, }); const inputNumber = new MTS.Input('#inp-number', { type: 'number', label: 'Cantidad', placeholder: '0', });

new MTS.Input('#inp-textarea', { type: 'textarea', label: 'Descripción', placeholder: 'Escribe aquí...', rows: 4, maxLength: 300, showCount: true, });

<!-- Disabled --> <div id="inp-disabled" data-label="Campo deshabilitado" data-value="No editable" data-disabled> </div> <!-- Readonly --> <div id="inp-readonly" data-label="Solo lectura" data-value="Valor fijo" data-readonly> </div> <!-- Clearable --> <div id="inp-clearable" data-label="Con botón limpiar" data-placeholder="Escribe algo..." data-clearable> </div> <!-- Con ícono (requiere JavaScript para pasar el SVG) --> <div id="inp-icon"></div> <script> new MTS.Input('#inp-disabled'); new MTS.Input('#inp-readonly'); new MTS.Input('#inp-clearable'); new MTS.Input('#inp-icon', { label: 'Buscar', placeholder: 'Buscar...', iconLeft: MTS.Icon.get('search'), clearable: true, }); </script>

4 — Validación con reglas
— interactúa con los campos, la validación ocurre al perder foco —
<!-- Las reglas de validación solo se pueden pasar por JavaScript --> <div id="inp-valid-email"></div> <div id="inp-valid-len"></div> <script> new MTS.Input('#inp-valid-email', { label: 'Email', placeholder: 'usuario@ejemplo.com', required: true, rules: { email: true }, onBlur: (e) => console.log('válido:', e.target.isValid()), }); new MTS.Input('#inp-valid-len', { label: 'Usuario', placeholder: 'mínimo 4, máximo 20 caracteres', rules: { minLength: 4, maxLength: 20 }, showCount: true, maxLength: 20, }); </script>
const inpEmail = new MTS.Input('#inp-valid-email', { label: 'Email', placeholder: 'usuario@ejemplo.com', required: true, rules: { email: true }, // validateOnBlur: true (default) // validateOnInput: false (default) }); const inpLen = new MTS.Input('#inp-valid-len', { label: 'Usuario', placeholder: 'mínimo 4, máximo 20 caracteres', rules: { minLength: 4, maxLength: 20 }, showCount: true, maxLength: 20, }); // API de validación inpEmail.validate() // → true | false inpEmail.isValid() // → boolean inpEmail.setError('Ya existe') inpEmail.clearError()
5 — Eventos: onChange · onFocus · onBlur · validate
— interactúa con el campo —
<!-- Con HTML declarativo, los callbacks van en el new MTS.Input --> <div id="inp-events" data-label="Campo con eventos" data-placeholder="Escribe algo..." data-hint="Observa los eventos en el panel inferior" data-required> </div> <script> new MTS.Input('#inp-events', { onChange: (e) => log('change → "' + e.detail.value + '"'), onFocus: (e) => log('focus'), onBlur: (e) => log('blur → "' + e.detail.value + '"'), }); // O usando eventos DOM nativos (sin instancia JS) document.getElementById('inp-events') .querySelector('input') .addEventListener('mts:input:validate', (e) => { log('validate → válido: ' + e.detail.valid); }); </script>
const inp = new MTS.Input('#inp-events', { label: 'Campo con eventos', placeholder: 'Escribe algo...', hint: 'Observa los eventos en el panel inferior', required: true, // Fires on every value change / Se dispara en cada cambio de valor onChange: (e) => log('change → "' + e.detail.value + '"'), // Fires when focused / Se dispara al enfocar onFocus: (e) => log('focus'), // Fires when focus is lost / Se dispara al perder foco onBlur: (e) => log('blur → "' + e.detail.value + '"'), // Fires after validation / Se dispara después de validar onValidate: (e) => { log('validate → válido: ' + e.detail.valid + (e.detail.errors.length ? ' | error: ' + e.detail.errors[0] : '')); }, });
6 — API programática
— usa los botones para llamar la API —
<div id="inp-api" data-label="Campo controlado" data-placeholder="Controlado por API"> </div> <script> const inp = new MTS.Input('#inp-api'); inp.getValue() // → string inp.setValue('Hola!') inp.clear() inp.disable() inp.enable() inp.setError('Mensaje de error externo') inp.clearError() inp.focus() </script>
const inp = new MTS.Input('#inp-api', { label: 'Campo controlado', placeholder: 'Controlado por API', }); inp.getValue() // → string inp.setValue('Hola!') // establece valor inp.clear() // limpia valor y error inp.disable() // deshabilita inp.enable() // habilita inp.setError('Mensaje de error') // error externo (ej: desde el servidor) inp.clearError() // limpia el error inp.focus() // foco programático inp.validate() // ejecuta validación manualmente → boolean inp.isValid() // → boolean inp.destroy() // destruye el componente
