MTS.RichTextEditor

WYSIWYG editor — contentEditable, no dependencies, no iframe.

1 — Toolbar completa / Full toolbar
— el HTML aparece aquí al escribir —
<div id="my-editor"></div> <script> new MTS.RichTextEditor('#my-editor', { placeholder: 'Start writing...', height: '240px', // Fires on every content change / Se dispara al cambiar el contenido onChange: (html) => console.log(html), onFocus: () => console.log('focused'), onBlur: (html) => console.log('blurred'), }); </script>
const rte = new MTS.RichTextEditor('#my-editor', { // Initial HTML / HTML inicial value: '<p>Hello <strong>world</strong></p>', placeholder: 'Start writing...', height: '240px', minHeight: '120px', // All toolbar groups / Todos los grupos de toolbar toolbar: ['format', 'lists', 'align', 'insert', 'clean'], // Fires on every change / Se dispara en cada cambio onChange: (html) => console.log(html), onFocus: () => console.log('focused'), onBlur: (html) => console.log('blurred'), });
2 — Toolbar personalizada / Custom toolbar
Solo formato / Format only
Formato + listas / Format + lists
<div id="editor-format"></div> <script> new MTS.RichTextEditor('#editor-format', { toolbar: ['format', 'clean'], height: '160px', }); </script>
// Toolbar groups: 'format' | 'lists' | 'align' | 'insert' | 'clean' | 'table' // Grupos de toolbar // Format only / Solo formato new MTS.RichTextEditor('#editor-format', { toolbar: ['format', 'clean'], height: '160px', }); // Format + lists / Formato + listas new MTS.RichTextEditor('#editor-lists', { toolbar: ['format', 'lists', 'clean'], height: '160px', });
3 — API
— usa los botones —
<div id="my-editor"></div> <script> const rte = new MTS.RichTextEditor('#my-editor', { value: '<p>Initial content</p>', }); rte.getValue() // → HTML string rte.getText() // → plain text rte.setValue('<p>New content</p>') rte.clear() rte.disable() rte.enable() rte.focus() rte.insertHTML('<strong>inserted</strong>') </script>
const rte = new MTS.RichTextEditor('#my-editor', { value: '<p>Initial <em>content</em></p>', onChange: (html) => console.log(html), }); // Get HTML / Obtener HTML rte.getValue() // → '<p>Initial <em>content</em></p>' // Get plain text / Obtener texto plano rte.getText() // → 'Initial content' // Set HTML / Establecer HTML rte.setValue('<p>New <strong>content</strong></p>') // Clear / Limpiar rte.clear() // Disable / enable / Deshabilitar / habilitar rte.disable() rte.enable() // Insert HTML at cursor / Insertar HTML en el cursor rte.insertHTML('<mark>highlighted</mark>')
