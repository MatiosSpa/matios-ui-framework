MTS Form Layout

Layouts de formulario — CSS puro. Stack · Grid · Horizontal · Inline · Secciones · Card  ·  🧪 Prueba de fuego →

1 — Stack (default)

El layout base. Label arriba, campo abajo, campos apilados verticalmente. No requiere clase adicional.

Te enviaremos la confirmación aquí. 
<form class="mts-form">
  <div class="mts-form-group">
    <label class="mts-form-label mts-form-label--required">Nombre</label>
    <input class="mts-input" placeholder="Juan Pérez">
  </div>
  <div class="mts-form-group">
    <label class="mts-form-label">Email</label>
    <input class="mts-input" type="email">
    <span class="mts-form-hint">Te enviaremos la confirmación aquí.</span>
  </div>
  <div class="mts-form-footer mts-form-footer--end">
    <button class="mts-btn mts-btn--secondary">Cancelar</button>
    <button class="mts-btn mts-btn--primary">Guardar</button>
  </div>
</form>
2 — Grid — 2 columnas

Distribución en columnas via CSS Variable --mts-form-cols. Colapsa a 1 columna en mobile.

<form class="mts-form mts-form--grid" style="--mts-form-cols:2">
  <div class="mts-form-group">
    <label class="mts-form-label">Nombre</label>
    <input class="mts-input">
  </div>
  <div class="mts-form-group">
    <label class="mts-form-label">Apellido</label>
    <input class="mts-input">
  </div>
  <!-- Ocupa las 2 columnas -->
  <div class="mts-form-group mts-form-group--full">
    <label class="mts-form-label">Dirección</label>
    <input class="mts-input">
  </div>
  <div class="mts-form-footer mts-form-footer--end mts-form-group--full">
    <button class="mts-btn mts-btn--primary">Guardar</button>
  </div>
</form>
3 — Grid — 3 columnas
<form class="mts-form mts-form--grid" style="--mts-form-cols:3">
  <div class="mts-form-group">...</div>
  <div class="mts-form-group">...</div>
  <div class="mts-form-group">...</div>
  <!-- span-2: ocupa 2 de las 3 columnas -->
  <div class="mts-form-group mts-form-group--span-2">...</div>
  <div class="mts-form-group">...</div>
</form>
4 — Horizontal

Label a la izquierda + campo a la derecha. Controla el ancho del label con --mts-form-label-width. Colapsa en mobile.

Mínimo 8 caracteres. 
<form class="mts-form mts-form--horizontal">
  <div class="mts-form-group">
    <label class="mts-form-label">Email</label>
    <input class="mts-input" type="email">
  </div>
  <div class="mts-form-group">
    <label class="mts-form-label">Contraseña</label>
    <input class="mts-input" type="password">
    <span class="mts-form-hint">Mínimo 8 caracteres.</span>
  </div>
</form>

<!-- Label más ancho -->
<form class="mts-form mts-form--horizontal" style="--mts-form-label-width:200px">
  ...
</form>
5 — Inline

Todos los campos en una línea. Ideal para filtros y barras de búsqueda.

<form class="mts-form mts-form--inline">
  <div class="mts-form-group">
    <label class="mts-form-label">Buscar</label>
    <input class="mts-input" placeholder="Nombre o email...">
  </div>
  <div class="mts-form-group">
    <label class="mts-form-label">Estado</label>
    <!-- MTS.Select -->
  </div>
  <button class="mts-btn mts-btn--primary">Buscar</button>
  <button class="mts-btn mts-btn--ghost">Limpiar</button>
</form>
6 — Secciones

Divide el formulario en bloques con separador visual y título de sección.

Datos personales

Información básica del usuario.

Contraseña

Debe tener al menos 8 caracteres.

<form class="mts-form">
  <div class="mts-form-section">
    <h3 class="mts-form-section__title">Datos personales</h3>
    <p class="mts-form-section__desc">Información básica.</p>
    <div class="mts-form-group">...</div>
  </div>
  <div class="mts-form-section">
    <h3 class="mts-form-section__title">Contraseña</h3>
    <div class="mts-form-group">...</div>
  </div>
</form>
7 — Form Card

Formulario envuelto en una card con header, título y padding.

Iniciar sesión

Ingresa tus credenciales para continuar.

<div class="mts-form-card">
  <div class="mts-form-card__header">
    <h2 class="mts-form-card__title">Iniciar sesión</h2>
    <p class="mts-form-card__subtitle">Ingresa tus credenciales.</p>
  </div>
  <form class="mts-form">
    <div class="mts-form-group">...</div>
    <div class="mts-form-footer mts-form-footer--between">
      <button class="mts-btn mts-btn--link">¿Olvidaste tu contraseña?</button>
      <button class="mts-btn mts-btn--primary">Entrar</button>
    </div>
  </form>
</div>
