MTS.FormLayout

Form layout system — pure CSS. Stack, grid, horizontal, inline, sections and card.

1 — Stack (default)
We'll send confirmations here.
<form class="mts-form"> <div class="mts-form-group"> <label class="mts-form-label mts-form-label--required" for="name">Full name</label> <input class="mts-input" id="name" placeholder="John Doe"> </div> <div class="mts-form-group"> <label class="mts-form-label" for="email">Email</label> <input class="mts-input" id="email" type="email"> <span class="mts-form-hint">We'll send confirmations here.</span> </div> <div class="mts-form-footer mts-form-footer--end"> <button class="mts-btn mts-btn--secondary">Cancel</button> <button class="mts-btn mts-btn--primary">Save</button> </div> </form>
.mts-form → stack layout (default) .mts-form-group → field wrapper .mts-form-label → label .mts-form-label--required → adds red asterisk * .mts-form-hint → helper text below field .mts-form-error → error text below field .mts-form-footer → button area .mts-form-footer--end → right-aligned buttons
2 — Grid — 2 columnas / 2 columns
<!-- --mts-form-cols controls column count / controla la cantidad de columnas --> <form class="mts-form mts-form--grid" style="--mts-form-cols:2"> <div class="mts-form-group">...</div> <div class="mts-form-group">...</div> <!-- Full-width field / Campo de ancho completo --> <div class="mts-form-group mts-form-group--full">...</div> </form> <!-- 3 columns / 3 columnas --> <form class="mts-form mts-form--grid" style="--mts-form-cols:3">...</form>
.mts-form--grid → grid layout --mts-form-cols: 2 → 2 columns --mts-form-cols: 3 → 3 columns .mts-form-group--full → spans all columns .mts-form-group--span-2 → spans 2 columns
3 — Grid — 3 columnas / 3 columns
<form class="mts-form mts-form--grid" style="--mts-form-cols:3"> <div class="mts-form-group">...</div> <div class="mts-form-group">...</div> <div class="mts-form-group">...</div> <!-- Span all 3 columns / Span las 3 columnas --> <div class="mts-form-group mts-form-group--full">...</div> </form>
style="--mts-form-cols:3" → 3 columns .mts-form-group--full → spans all 3 .mts-form-group--span-2 → spans 2 of 3
4 — Horizontal
Minimum 8 characters.
<form class="mts-form mts-form--horizontal"> <div class="mts-form-group"> <label class="mts-form-label">Email</label> <input class="mts-input" type="email"> </div> </form> <!-- Custom label width / Ancho de label personalizado --> <form class="mts-form mts-form--horizontal" style="--mts-form-label-width:200px"> ... </form>
.mts-form--horizontal → label left, field right --mts-form-label-width: 160px → default label width --mts-form-label-width: 200px → wider label
5 — Inline
