MTS CopyButton

Copia texto al portapapeles con feedback visual automático

1 — Variantes y tamaños
new MTS.CopyButton('#btn', {
  text:    'npm install matios-ui',
  variant: 'secondary',  // 'primary' | 'ghost' | etc.
  size:    '',           // 'sm' | '' | 'lg'
})
2 — Solo ícono
new MTS.CopyButton('#btn', {
  text:     'texto a copiar',
  iconOnly: true,
  variant:  'ghost',
  size:     'sm',
})
3 — Inline con input — copy group
<div class="mts-copy-group">
  <input id="api-key" class="mts-input" value="sk-..." readonly>
  <button id="btn-copy"></button>
</div>

<script>
new MTS.CopyButton('#btn-copy', {
  target:  '#api-key',
  iconOnly: true,
  variant:  'primary',
})
</script>
4 — Bloque de código
npm install matios-ui
<link rel="stylesheet" href="base/matios-ui-base.css">
<link rel="stylesheet" href="base/matios-ui-grid.css">
<script src="forms/matios-ui-input/matios-ui-input.js"></script>
<div style="position:relative">
  <pre id="code-block">npm install matios-ui</pre>
  <button id="btn-copy" style="position:absolute;top:8px;right:8px"></button>
</div>

new MTS.CopyButton('#btn-copy', {
  target:   '#code-block',
  iconOnly: true,
  size:     'sm',
  variant:  'ghost',
})
5 — Con callback onCopy
Copia el texto para ver el callback...
new MTS.CopyButton('#btn', {
  text:    'Texto con callback',
  onCopy:  (text) => {
    console.log('Copiado:', text)
    MTS.Toast.show({ message: 'Copiado al portapapeles', variant: 'success' })
  },
})
HTML declarativo
— copia algo —
<button id="c1" data-text="npm install matios-ui" data-label="Copiar" data-variant="secondary"></button>
<input id="apiKey" value="sk-abc123" readonly>
<button id="c2" data-target="#apiKey" data-icon-only data-variant="ghost"></button>
<script>
new MTS.CopyButton('#c1', { onCopy: (t) => console.log('copiado:', t) })
new MTS.CopyButton('#c2')
</script>
