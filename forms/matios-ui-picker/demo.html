MTS.Picker

Selectores de fecha, hora, rango, mes, semana y color.

1 — Fecha, Hora y Fecha+Hora
Fecha (Date)
Hora (Time) — Aceptar para confirmar
Fecha y Hora (DateTime)
new MTS.Picker.Date('#el',{format:'DD/MM/YYYY',clearable:true,onChange:(e)=>console.log(e.detail.formatted)})
new MTS.Picker.Time('#el',{timeStep:5,btnNow:'Ahora',btnAccept:'Aceptar',onChange:(e)=>console.log(e.detail.formatted)})
new MTS.Picker.DateTime('#el',{format:'DD/MM/YYYY',timeStep:5,btnToday:'Hoy',onChange:(e)=>console.log(e.detail.formatted)})
2 — Rango de fechas — selecciona inicio → fin → Aceptar
new MTS.Picker.DateRange('#el',{format:'DD/MM/YYYY',btnClear:'Limpiar',btnAccept:'Aplicar',onChange:(e)=>{console.log(e.detail.value.start,e.detail.value.end)}})
3 — Mes, Semana y Color
Mes y Año (Month)
Semana (Week)
Color (hex/rgb/hsl)
new MTS.Picker.Month('#el',{onChange:(e)=>console.log(e.detail.formatted)})
new MTS.Picker.Week('#el',{onChange:(e)=>console.log(e.detail.formatted)})
new MTS.Picker.Color('#el',{value:'#4f8eff',colorFormat:'hex',onChange:(e)=>console.log(e.detail.value)})
