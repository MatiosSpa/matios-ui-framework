MTS.DatePicker

Selectores de fecha, hora, rango, mes, semana y color. Cada tipo es una clase independiente.

1 — Date / Time / DateTime
Fecha / Date
— selecciona una fecha —
Hora / Time
— selecciona una hora —
Fecha + Hora / DateTime
— selecciona fecha y hora —
<input type="text" id="picker-date"> <input type="text" id="picker-time"> <input type="text" id="picker-datetime">
// Fecha / Date new MTS.DatePicker.Date('#picker-date', { format: 'DD/MM/YYYY', clearable: true, onChange: (e) => console.log(e.detail.value, e.detail.formatted), }); // Hora / Time new MTS.DatePicker.Time('#picker-time', { timeStep: 5, startHour: 8, endHour: 20, btnNow: 'Ahora', btnAccept: 'Aceptar', onChange: (e) => console.log(e.detail.formatted), // → '09:30' }); // Fecha + Hora / DateTime new MTS.DatePicker.DateTime('#picker-datetime', { format: 'DD/MM/YYYY', timeStep: 5, btnToday: 'Hoy', btnAccept: 'Aceptar', onChange: (e) => console.log(e.detail.value, e.detail.formatted), });
2 — Date Range / Rango de fechas
— selecciona inicio → fin —
<input type="text" id="picker-range">
const rp = new MTS.DatePicker.DateRange('#picker-range', { format: 'DD/MM/YYYY', btnClear: 'Limpiar', btnAccept: 'Aplicar', onChange: (e) => { console.log(e.detail.value.start); // Date inicio console.log(e.detail.value.end); // Date fin console.log(e.detail.formatted); // '01/03/2025 → 15/03/2025' }, }); // Establecer valor programático rp.setValue([new Date('2025-03-01'), new Date('2025-03-15')]); rp.getValue(); // → { start: Date, end: Date }

4 — API común / Common API
<!-- Cualquier input de texto — el picker lo convierte en selector —> <input type="text" id="mi-picker">
const picker = new MTS.DatePicker.Date('#mi-picker', { format: 'DD/MM/YYYY' }); // Métodos disponibles en todos los tipos picker.open(); picker.close(); picker.getValue(); // → Date | string | { start, end } picker.setValue(new Date()); // chainable picker.clear(); picker.destroy(); // Eventos vía .on() picker.on('change', (e) => { e.detail.value; // valor nativo (Date, string, objeto) e.detail.formatted; // string formateado visible en el input }); picker.on('open', () => {}); picker.on('close', () => {}); // Eventos DOM document.getElementById('mi-picker') .addEventListener('mts:picker:change', (e) => { console.log(e.detail.value, e.detail.formatted); });
