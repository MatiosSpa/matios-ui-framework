MTS Label

Label de formulario — texto, requerido, opcional, hint, error, tamaños

1 — Variantes — CSS puro
<!-- Simple -->
<label class="mts-label" for="campo">Nombre</label>

<!-- Requerido -->
<label class="mts-label mts-label--required" for="email">Email</label>

<!-- Opcional -->
<label class="mts-label mts-label--optional">
  <span class="mts-label__text">Teléfono</span>
  <span class="mts-label__optional">opcional</span>
</label>
2 — Con hint y error
Nunca compartiremos tu email.
La contraseña debe tener al menos 8 caracteres. 
<div class="mts-form-group">
  <label class="mts-label mts-label--required">Email</label>
  <input class="mts-input" type="email">
  <span class="mts-form-hint">Nunca compartiremos tu email.</span>
</div>

<div class="mts-form-group">
  <label class="mts-label mts-label--required">Contraseña</label>
  <input class="mts-input" type="password">
  <span class="mts-form-error">Debe tener al menos 8 caracteres.</span>
</div>
3 — Tamaños
<label class="mts-label mts-label--sm">Compacto</label>
<label class="mts-label">Normal</label>
<label class="mts-label mts-label--lg">Grande</label>
4 — Via JS — MTS.Label
const lbl = new MTS.Label('#mi-label', {
  text:     'Nombre completo',
  required: true,
  hint:     'Tal como aparece en tu documento.',
  forId:    'mi-input',
})

// API
lbl.setText('Nuevo texto')
lbl.setHint('Texto de ayuda')
lbl.setError('Campo requerido')
lbl.clearError()
lbl.setRequired(true)
5 — Label oculto — accesible

El label existe en el DOM para screen readers pero no es visible. Útil en formularios inline.

<label class="mts-label mts-label--hidden" for="buscar">Buscar</label>
<input class="mts-input" id="buscar" placeholder="Buscar...">

<!-- Via JS -->
new MTS.Label('#lbl', { text:'Buscar', hidden:true, forId:'buscar' })
