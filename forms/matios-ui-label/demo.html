MTS.Label

Form label with required/optional badges, hint text, error state and size variants.

1 — HTML puro / Pure HTML (no JS required)
<!-- Basic / Básico --> <div class="mts-form-group"> <label class="mts-label" for="name">Full name</label> <input class="mts-input" id="name"> </div> <!-- Required / Requerido --> <div class="mts-form-group"> <label class="mts-label mts-label--required" for="email">Email</label> <input class="mts-input" id="email" type="email"> </div> <!-- Optional / Opcional --> <div class="mts-form-group"> <label class="mts-label" for="phone"> <span class="mts-label__text">Phone</span> <span class="mts-label__optional">optional</span> </label> <input class="mts-input" id="phone"> </div>
// Required / Requerido new MTS.Label('#my-label', { text: 'Email address', required: true, forId: 'input-email', }); // Optional / Opcional new MTS.Label('#my-label', { text: 'Phone number', optional: true, forId: 'input-phone', });
2 — Con hint y error / With hint and error
We'll never share your email.
Minimum 8 characters required.
<!-- With hint / Con hint --> <div class="mts-form-group"> <label class="mts-label mts-label--required" for="email">Email</label> <input class="mts-input" id="email" type="email"> <span class="mts-form-hint">We'll never share your email.</span> </div> <!-- With error / Con error --> <div class="mts-form-group"> <label class="mts-label mts-label--required" for="pass">Password</label> <input class="mts-input" id="pass" type="password"> <span class="mts-form-error">Minimum 8 characters required.</span> </div>
// With hint / Con hint new MTS.Label('#my-label', { text: 'Email address', required: true, hint: "We'll never share your email.", forId: 'input-email', }); // With error / Con error const lbl = new MTS.Label('#my-label', { text: 'Password', required: true, }); // Set error at runtime / Establecer error en runtime lbl.setError('Minimum 8 characters required.') // Clear error / Limpiar error lbl.clearError()
3 — Tamaños / Sizes
<label class="mts-label mts-label--sm">Small label</label> <label class="mts-label">Default label</label> <label class="mts-label mts-label--lg">Large label</label>
// Size: 'sm' | '' | 'lg' / Tamaño new MTS.Label('#lbl-sm', { text: 'Small label', size: 'sm' }); new MTS.Label('#lbl-md', { text: 'Default label', size: '' }); new MTS.Label('#lbl-lg', { text: 'Large label', size: 'lg' });
4 — API via JavaScript
<div id="my-label"></div> <input class="mts-input" id="my-input"> <script> const lbl = new MTS.Label('#my-label', { text: 'Full name', required: true, hint: 'As it appears on your ID', forId: 'my-input', }); lbl.setError('This field is required') lbl.clearError() lbl.setText('New label text') lbl.setRequired(false) </script>
const lbl = new MTS.Label('#my-label', { text: 'Full name', required: true, hint: 'As it appears on your ID', forId: 'my-input', }); // Change text at runtime / Cambiar texto en runtime lbl.setText('Updated label') // Add/remove hint / Agregar/quitar hint lbl.setHint('Helper text') // Show/clear error / Mostrar/limpiar error lbl.setError('This field is required') lbl.clearError() // Toggle required asterisk / Alternar asterisco requerido lbl.setRequired(true) lbl.setRequired(false)
5 — Oculto accesible / Visually hidden

[EN] The label is invisible but accessible to screen readers.
[ES] El label es invisible pero accesible para screen readers.

<!-- Visually hidden but accessible / Oculto visualmente pero accesible --> <label class="mts-label mts-label--hidden" for="search"> Search products </label> <input class="mts-input" id="search" placeholder="Search products...">
new MTS.Label('#my-label', { text: 'Search products', hidden: true, // visible to screen readers / visible para screen readers forId: 'search-input', });
