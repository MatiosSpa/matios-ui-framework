MTS.KPICard

Tarjetas de métricas con tendencia, sparkline y variantes de color.

1 — Variantes con sparkline
new MTS.KPICard('#el', {
  label:      'Documentos subidos',
  value:      '1,248',
  unit:       '',             // unidad opcional: '%', '$', 'ms'...
  trend:       12.5,          // positivo = verde ↑, negativo = rojo ↓
  trendLabel: 'vs mes anterior',
  sparkline:  [42,38,55,60,48,72,65,80],   // datos para mini gráfico
  variant:    'primary',      // 'default'|'primary'|'success'|'warning'|'danger'
  onClick:    () => console.log('kpi click'),
})
2 — Con íconos
new MTS.KPICard('#el', {
  label:   'Ventas del mes',
  value:   '$48,320',
  trend:    8.3,
  icon:    MTS.Icon.get('bar-chart'),
  variant: 'success',
})
3 — API — update() en tiempo real
— actualiza la métrica en vivo —
const kpi = new MTS.KPICard('#el', {
  label:    'Requests/seg',
  value:     0,
  variant:  'primary',
  sparkline: [],
})

// Actualizar valores
kpi.update({
  value:      1248,
  trend:      12.5,
  sparkline:  [42,55,48,72,65,80],
})
