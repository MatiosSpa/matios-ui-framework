MTS.Timeline

Línea de tiempo vertical con alineaciones y eventos clickeables.

1 — Vertical izquierda (con eventos y badges)
— haz click en un evento —
new MTS.Timeline('#el', {
  direction: 'vertical',
  align:     'left',
  events: [
    {
      id:    'e1',
      title: 'Documento creado',
      description: 'contrato_final.pdf subido por Juan Pérez',
      date:  '26/03/2026 10:30',
      color: '#4f8eff',
      badge: { label:'Completado', variant:'success' },
    },
    { id:'e2', title:'En revisión', date:'25/03/2026',
      badge:{ label:'Revisión', variant:'warning' } },
  ],
  onEventClick: (event, index) => console.log('click:', event.title),
})
2 — Vertical alternada
new MTS.Timeline('#el', {
  direction: 'vertical',
  align:     'alternate',   // eventos alternados izq/der
  events: [...]
})
3 — Con íconos custom por evento
new MTS.Timeline('#el', {
  events: [
    { title:'Desplegado',  icon:MTS.Icon.get('upload'),   color:'#4f8eff' },
    { title:'Testeado',    icon:MTS.Icon.get('check-circle'), color:'#34d399' },
    { title:'Error en CI', icon:MTS.Icon.get('alert'),    color:'#f87171' },
    { title:'Iniciado',    icon:MTS.Icon.get('play'),     color:'#a78bfa' },
  ],
})
4 — API — addEvent() dinámico
const tl = new MTS.Timeline('#el', { events:[] })

tl.addEvent({
  id:    Date.now().toString(),
  title: 'Nuevo evento',
  date:  new Date().toLocaleString('es-CL'),
  badge: { label:'Nuevo', variant:'primary' },
})

tl.setEvents([...])  // reemplazar todos los eventos
