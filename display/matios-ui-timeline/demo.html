MTS.Timeline

Vertical or horizontal timeline — icons, badges, dates, colors, clickable events.

1 — Vertical izquierda con badges / Left vertical with badges
— haz click en un evento —
<div id="my-timeline"></div> <script> new MTS.Timeline('#my-timeline', { direction: 'vertical', align: 'left', events: [ { id:'deploy', title:'Production deploy', date:'2 min ago', badge:{ label:'Success', variant:'success' } }, { id:'review', title:'Code review', date:'1h ago', description:'PR #142 approved.' }, { id:'commit', title:'Commit pushed', date:'Yesterday' }, ], // Fires on item click / Se dispara al hacer click en un ítem onEventClick: (e) => { console.log(e.detail.event.id); // → 'deploy' console.log(e.detail.index); // → 0 }, }); </script>
new MTS.Timeline('#my-timeline', { direction: 'vertical', align: 'left', events: [ { id:'deploy', title:'Production deploy', date:'2 min ago', badge:{ label:'Success', variant:'success' }, description:'v2.4.0 deployed correctly.' }, { id:'review', title:'Code review passed', date:'1h ago', badge:{ label:'Approved', variant:'primary' }, description:'PR #142 merged.' }, { id:'ci', title:'CI pipeline', date:'2h ago', badge:{ label:'Passed', variant:'info' } }, { id:'commit', title:'Commit pushed', date:'Yesterday', description:'feat: add dark mode support' }, { id:'branch', title:'Branch created', date:'2 days ago' }, ], // Fires when item is clicked / Se dispara al hacer click en ítem onEventClick: (e) => { console.log(e.detail.event.id); // → 'deploy' console.log(e.detail.index); // → 0 }, });

4 — addEvent() dinámico / Dynamic addEvent()
<div id="my-timeline"></div> <script> const tl = new MTS.Timeline('#my-timeline', { events: [] }); // Add one event / Agregar un evento tl.addEvent({ id:'new', title:'New event', date:'Just now' }); // Replace all / Reemplazar todos tl.setEvents([...]); </script>
const tl = new MTS.Timeline('#my-timeline', { events: [{ title:'Initial event', date:'Start' }], onEventClick: (e) => console.log(e.detail.event.title), }); // Add event dynamically / Agregar evento dinámicamente tl.addEvent({ id: 'new-' + Date.now(), title: 'New event', date: 'Just now', badge: { label: 'New', variant: 'primary' }, description: 'Added at runtime.', }); // Replace all events / Reemplazar todos los eventos tl.setEvents([ { title: 'Reset event 1', date: 'Yesterday' }, { title: 'Reset event 2', date: 'Today' }, ]);
