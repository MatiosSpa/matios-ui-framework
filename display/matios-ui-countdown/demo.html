MTS.Countdown

Animated countdown timer — blocks, compact, minimal · pause/resume · onTick/onComplete.

1 — Variant: blocks (default)

const cd = new MTS.Countdown('#my-countdown', { target: new Date(Date.now() + 60000), variant: 'blocks', // Fires every second / Se dispara cada segundo onTick: (e) => { console.log(`${e.detail.hours}:${e.detail.mins}:${e.detail.secs}`); }, // Fires when reaches zero / Se dispara al llegar a cero onComplete: (e) => console.log('Time is up!'), }); cd.pause() // pause timer / pausar cd.resume() // resume / reanudar cd.setTarget(new Date(Date.now() + 3600000)) // new target / nuevo objetivo cd.setTarget('2026-12-31T23:59:59') // ISO string also works cd.destroy() // stop and clear DOM
