MTS.SortableList

Lista reordenable con drag & drop, botones ↑ ↓ y eventos de reorden.

1 — Workflow de aprobaciones — numbered + moveButtons + disabled

💡 El primer aprobador está fijo (disabled). Arrastra o usa ↑ ↓ para reordenar los demás.

— reordena los aprobadores —
new MTS.SortableList('#el', {
  numbered:    true,
  moveButtons: true,
  items: [
    { id:'1', title:'Juan Pérez',    description:'Gerente General',
      avatar:'Juan Pérez',    badge:{ label:'Fijo', variant:'danger' }, disabled:true },
    { id:'2', title:'María Alarcón', description:'Jefe de Proyecto',
      avatar:'María Alarcón', badge:{ label:'Aprobador', variant:'primary' } },
    { id:'3', title:'Carlos Ruiz',   description:'Revisor Técnico',
      avatar:'Carlos Ruiz',   badge:{ label:'Revisor', variant:'default' } },
  ],
  onReorder: (e) => {
    console.log('Nuevo orden:', e.detail.items.map(i => i.title))
    console.log('item movido:', e.detail.item.title)
    console.log('de:', e.detail.fromIndex, '→ a:', e.detail.toIndex)
  },
})

4 — Orden de columnas de tabla

💡 Reordena y el resultado representa el nuevo orden de columnas.

— reordena las columnas —
new MTS.SortableList('#el', {
  variant:  'compact',
  numbered:  true,
  items: columns.map(col => ({
    id:    col.key,
    title: col.label,
    icon:  MTS.Icon.get(col.icon),
    badge: col.visible
      ? { label:'Visible', variant:'success' }
      : { label:'Oculta',  variant:'default' },
  })),
  onReorder: (e) => aplicarOrdenColumnas(e.detail.items),
})
5 — API — addItem · removeItem · lock · unlock
— usa los botones para probar la API —
const list = new MTS.SortableList('#el', { items:[...] })

list.addItem({ id:'nuevo', title:'Nuevo item', description:'...' })
list.addItem({ id:'top',   title:'Al inicio' }, 0)   // índice 0 = al principio
list.removeItem('id-a-eliminar')
list.updateItem('id', { title:'Nuevo título', badge:{ label:'Editado', variant:'warning' } })
list.lock()     // modo solo lectura
list.unlock()   // vuelve a ser reordenable
list.getItems() // → copia del array actual

// Escuchar eventos
list.on('reorder',   (e) => console.log(e.detail.fromIndex, '→', e.detail.toIndex))
list.on('itemClick', (e) => console.log('click:', e.detail.item.title))
