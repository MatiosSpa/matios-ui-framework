3 — Hoverable y clickable / Hoverable and clickable
— haz click en la card clickeable —
<div id="my-card"></div> <script> new MTS.Card('#my-card', { title: 'Clickable card', body: '<p>Click anywhere on the card.</p>', clickable: true, hoverable: true, // Fires when card is clicked / Se dispara al hacer click onClick: (e) => { console.log(e.detail.card); // → MTS.Card instance console.log(e.detail.event); // → MouseEvent }, }); </script>
// Hoverable / Con efecto hover new MTS.Card('#card-hover', { title: 'Hoverable', body: '<p>Hover to see lift effect.</p>', hoverable: true, }); // Clickable / Clickeable new MTS.Card('#card-click', { title: 'Clickable', body: '<p>Click anywhere on the card.</p>', clickable: true, hoverable: true, // Fires when card is clicked / Se dispara al hacer click onClick: (e) => { console.log(e.detail.card); // → MTS.Card instance console.log(e.detail.event); // → MouseEvent }, });
