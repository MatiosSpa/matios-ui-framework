MTS Card

Card genérica — header · body · footer · imagen · variantes · hover · clickable

1 — Estructura base — CSS puro
Card básica
Subtítulo opcional
Cuerpo de la card con contenido de ejemplo. Puede contener cualquier HTML.
Elevated
Con sombra media
Card con sombra y sin borde. Ideal para destacar contenido.
Outlined
Borde fuerte, fondo transparente
Variante outlined para contextos sobre fondos con color.
<div class="mts-card">

    </div>

  <div class="mts-card__footer mts-card__footer--end">

2 — Acentos de color
Primary
Acento azul en borde izquierdo.
Success
Acento verde — operación exitosa.
Warning
Acento naranja — requiere atención.
Danger
Acento rojo — acción destructiva.
3 — Hoverable y Clickable
Hoverable
Pasa el mouse por encima
Efecto de sombra y lift al hacer hover. Sin interacción de click.
Clickable
Haz click en la card
Toda la card es clickeable. Cursor pointer y efecto active.
Selected
Estado seleccionado
Borde primario que indica selección activa.
4 — Tamaños
Small
Padding reducido, fuente más pequeña.
Default
Tamaño estándar del framework.
Large
Padding generoso para contenido destacado.
5 — Via JS — MTS.Card
const card = new MTS.Card('#mi-card', {
  title:    'Título de la card',
  subtitle: 'Subtítulo opcional',
  body:     '<p>Contenido HTML del cuerpo.</p>',
  variant:  'elevated',
  hoverable: true,
  clickable: true,
  actions: [
    { icon: '✏️', variant: 'ghost', onClick: () => {} },
    { icon: '🗑️', variant: 'ghost', onClick: () => {} },
  ],
  footer: [
    { label: 'Cancelar', variant: 'ghost',   onClick: () => {} },
    { label: 'Guardar',  variant: 'primary',  onClick: () => {} },
  ],
  footerAlign: 'end',
  onClick: (e, card) => console.log('clickeada'),
})
