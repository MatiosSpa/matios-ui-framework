MTS.VirtualList

Lista virtualizada para datasets de miles de ítems con rendimiento constante.

1 — 100.000 ítems virtualizados
El DOM solo contiene ~20 elementos aunque la lista tiene 100.000 filas.
— haz scroll —
new MTS.VirtualList('#el', {
  height:     400,
  itemHeight: 52,
  items:      users,  // array de 100.000 elementos
  renderItem: (user, idx) => {
    const div = document.createElement('div')
    div.className = 'row'
    div.innerHTML = idx + '. ' + user.name
    return div
  },
  onScroll: ({ firstVisible, lastVisible }) => {},
  onEndReached: ({ total }) => cargarMas(),
})
