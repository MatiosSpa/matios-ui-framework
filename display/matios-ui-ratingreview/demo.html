MTS.RatingReview

Rating review widget — average score, star display, breakdown bars, interactive voting.

1 — Solo lectura con breakdown / Read-only with breakdown
size: md (default)
size: lg
<div id="my-widget"></div> <script> new MTS.RatingReview('#my-widget', { average: 4.3, total: 1284, size: 'md', breakdown: { 5: 720, 4: 380, 3: 120, 2: 48, 1: 16 }, }); </script>
// Read-only display / Visualización de solo lectura new MTS.RatingReview('#my-widget', { average: 4.3, // average score (1-5) / promedio (1-5) total: 1284, // total review count / total de reseñas size: 'md', // 'sm' | 'md' | 'lg' breakdown: { 5: 720, // count per star / cantidad por estrella 4: 380, 3: 120, 2: 48, 1: 16, }, });
2 — Interactivo — permite votar / Interactive voting
— haz click en las estrellas para calificar —
<div id="my-widget"></div> <script> new MTS.RatingReview('#my-widget', { average: 4.3, total: 1284, breakdown: { 5:720, 4:380, 3:120, 2:48, 1:16 }, interactive: true, // shows clickable stars at bottom // Fires when user rates / Se dispara al calificar onRate: (e) => { console.log(e.detail.stars); // → 4 submitRating(e.detail.stars); }, }); </script>
const widget = new MTS.RatingReview('#my-widget', { average: 4.3, total: 1284, breakdown: { 5: 720, 4: 380, 3: 120, 2: 48, 1: 16 }, interactive: true, // shows clickable stars below breakdown // Fires when user rates / Se dispara al calificar onRate: (e) => { console.log(e.detail.stars); // → 1-5 // Optimistically update breakdown / Actualizar optimistamente widget.update({ total: widget.total + 1, average: ((widget.average * widget.total) + e.detail.stars) / (widget.total + 1), breakdown: { ...widget.breakdown, [e.detail.stars]: widget.breakdown[e.detail.stars] + 1 }, }); }, });
3 — update() — actualizar datos en vivo / Live data update
— usa los botones para simular nuevas reseñas —
<div id="my-widget"></div> <script> const w = new MTS.RatingReview('#my-widget', { average: 4.3, total: 1284, breakdown: { 5:720, 4:380, 3:120, 2:48, 1:16 }, }); // Update any option and re-render / Actualizar cualquier opción y re-renderizar w.update({ average: 4.5, total: 1300, breakdown: { 5:750, 4:380, 3:110, 2:48, 1:12 }, }); </script>
const w = new MTS.RatingReview('#my-widget', { average: 4.3, total: 1284, breakdown: { 5: 720, 4: 380, 3: 120, 2: 48, 1: 16 }, }); // Update with new review / Actualizar con nueva reseña function addReview(stars) { const newTotal = w.total + 1; const newAverage = ((w.average * w.total) + stars) / newTotal; const newBreakdown = { ...w.breakdown, [stars]: w.breakdown[stars] + 1 }; w.update({ average: +newAverage.toFixed(2), total: newTotal, breakdown: newBreakdown, }); }
