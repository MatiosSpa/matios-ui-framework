# Display

🇬🇧 Visualization and content presentation components. They do not receive direct user input — their role is to display data, states and collections clearly and consistently with the MTS design system.
🇪🇸 Componentes de visualización y presentación de contenido. No reciben input del usuario directamente — su rol es mostrar datos, estados y colecciones de forma clara y consistente con el sistema de diseño MTS.

---

## Components / Componentes

| Componente | Clase JS | 🇬🇧 Description / 🇪🇸 Descripción |
|---|---|---|
| `matios-ui-avatar` | `MTS.Avatar` | 🇬🇧 Avatar with image, initials or icon. Size/shape variants and stacked avatar groups. / 🇪🇸 Avatar con imagen, iniciales o icono. Variantes de tamaño, forma y grupo de avatares apilados. |
| `matios-ui-card` | `MTS.Card` | 🇬🇧 Generic card with header, body, footer, image, variants and hoverable/clickable states. / 🇪🇸 Tarjeta genérica con header, body, footer, imagen, variantes y estados hoverable/clickable. |
| `matios-ui-countdown` | `MTS.Countdown` | 🇬🇧 Animated countdown timer — blocks, compact, minimal and imperative API. / 🇪🇸 Temporizador regresivo animado — bloques, compacto, minimal y API imperativa. |
| `matios-ui-emptystate` | `MTS.EmptyState` | 🇬🇧 Empty state with icon, title, description and CTA action. For lists, searches and errors. / 🇪🇸 Estado vacío con icono, título, descripción y acción CTA. Para listas, búsquedas y errores. |
| `matios-ui-imagegallery` | `MTS.ImageGallery` | 🇬🇧 Image gallery with grid/masonry/list layouts, category filters and multi-selection. / 🇪🇸 Galería de imágenes con layouts grid/masonry/list, filtros por categoría y multi-selección. |
| `matios-ui-kanban` | `MTS.Kanban` | 🇬🇧 Kanban board with columns, drag & drop cards and event API. / 🇪🇸 Board Kanban con columnas, tarjetas drag & drop y API de eventos. |
| `matios-ui-kpicard` | `MTS.KPICard` | 🇬🇧 Metric card with main value, trend, sparkline and color variants. / 🇪🇸 Tarjeta de métrica con valor principal, tendencia, sparkline y variantes de color. |
| `matios-ui-ratingreview` | `MTS.RatingReview` | 🇬🇧 Review widget with average, star breakdown and interactive voting. / 🇪🇸 Widget de reseñas con promedio, breakdown por estrellas y votación interactiva. |
| `matios-ui-sortablelist` | `MTS.SortableList` | 🇬🇧 Drag & drop sortable list with numbering, move buttons, icons and badges. / 🇪🇸 Lista ordenable por drag & drop con numeración, botones de movimiento, iconos y badges. |
| `matios-ui-timeline` | `MTS.Timeline` | 🇬🇧 Vertical timeline with items, icons, color variants and alternating layout. / 🇪🇸 Línea de tiempo vertical con ítems, iconos, variantes de color y layout alternado. |
| `matios-ui-tree` | `MTS.Tree` | 🇬🇧 Tree view with expand/collapse, single/multiple selection and checkboxes. / 🇪🇸 Vista de árbol con expand/collapse, selección simple/múltiple y checkboxes. |
| `matios-ui-virtuallist` | `MTS.VirtualList` | 🇬🇧 Virtualized list — renders only visible items. Supports 100,000+ rows with infinite scroll. / 🇪🇸 Lista virtualizada — renderiza solo los ítems visibles. Soporta 100.000+ filas con scroll infinito. |

---

## Notes / Notas

- 🇬🇧 `MTS.VirtualList` is the right component for large lists — do not use `matios-ui-table` for high-volume flat lists. / 🇪🇸 `MTS.VirtualList` es el componente indicado para listas largas — no usar `matios-ui-table` para listas planas de gran volumen.
- 🇬🇧 `MTS.Kanban` and `MTS.SortableList` include their own drag & drop logic — no external dependencies. / 🇪🇸 `MTS.Kanban` y `MTS.SortableList` incluyen lógica drag & drop propia, sin dependencias externas.
- 🇬🇧 `MTS.EmptyState` is the system's standard empty state — use it consistently instead of ad-hoc messages. / 🇪🇸 `MTS.EmptyState` es el estado vacío estándar del sistema — usar consistentemente en lugar de mensajes ad-hoc.
