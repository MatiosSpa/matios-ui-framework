MTS.EmptyState

Empty state placeholder — no-data, search, error, permissions, custom · sizes · CTA button.

1 — Variantes predefinidas / Preset variants
— haz click en un botón CTA —
<div id="my-empty"></div> <script> new MTS.EmptyState('#my-empty', { variant: 'no-data', title: 'No items yet', description: 'Create your first item to get started.', action: 'Add item', // Fires when CTA is clicked / Se dispara al hacer click en el CTA onAction: (e) => openDialog(), }); </script>
// No data / Sin datos new MTS.EmptyState('#es-nodata', { variant: 'no-data', action: 'Agregar ítem', // Fires when CTA button is clicked / Se dispara al hacer click en el botón CTA onAction: (e) => console.log('add'), }); // Search — no results / Sin resultados de búsqueda new MTS.EmptyState('#es-search', { variant: 'search', title: 'Sin resultados para "dashboard"', description: 'Prueba con otras palabras.', action: 'Limpiar búsqueda', onAction: (e) => console.log('clear'), }); // Error state / Estado de error new MTS.EmptyState('#es-error', { variant: 'error', action: 'Reintentar', onAction: (e) => reload(), }); // Permissions / Sin permisos new MTS.EmptyState('#es-perms', { variant: 'permissions', description: 'Contacta al administrador.', });
2 — Tamaños / Sizes
<div id="es-sm"></div> <div id="es-md"></div> <div id="es-lg"></div> <script> ['sm','md','lg'].forEach(size => { new MTS.EmptyState('#es-' + size, { variant: 'no-data', size, }); }); </script>
// Sizes: 'sm' | 'md' | 'lg' ['sm', 'md', 'lg'].forEach(size => { new MTS.EmptyState('#es-' + size, { variant: 'no-data', size, action: 'Add item', }); });
3 — Custom + update() dinámico
<div id="my-empty"></div> <script> const es = new MTS.EmptyState('#my-empty', { variant: 'no-data' }); // Update any option and re-render / Actualizar cualquier opción es.update({ variant: 'search', title: 'No results for "xyz"', description: 'Try different keywords.', action: 'Clear search', }); </script>
const es = new MTS.EmptyState('#my-empty', { variant: 'no-data' }); // Update any option and re-render / Actualizar cualquier opción y re-renderizar es.update({ variant: 'search', title: 'Sin resultados' }); es.update({ variant: 'error', action: 'Reintentar' }); // Custom icon / Ícono personalizado es.update({ variant: 'custom', icon: '<svg>...</svg>', title: 'No messages', description: 'Start a conversation.', action: 'New message', });
