MTS.ImageGallery

Image gallery — grid, masonry, list · filters by category · multi-selection · built-in lightbox.

1 — Grid con filtros y lightbox / Grid with filters and lightbox
— haz click en una imagen para abrirla —
<div id="my-gallery"></div> <script> new MTS.ImageGallery('#my-gallery', { layout: 'grid', cols: 3, filters: true, lightbox: true, images: [ { id:'1', src:'/img/1.jpg', caption:'Mountain', category:'nature' }, { id:'2', src:'/img/2.jpg', caption:'Ocean', category:'nature' }, { id:'3', src:'/img/3.jpg', caption:'City', category:'urban' }, ], // Fires when image opens in lightbox / Se dispara al abrir en lightbox onOpen: (e) => { console.log(e.detail.image.id); // → '1' console.log(e.detail.image.caption); console.log(e.detail.index); // → 0 }, }); </script>
new MTS.ImageGallery('#my-gallery', { layout: 'grid', cols: 3, gap: '8px', filters: true, // shows category filter buttons / botones de filtro por categoría lightbox: true, // click opens lightbox / click abre lightbox images: IMAGES, // see image schema below / ver esquema de imagen abajo // Fires when image opens in lightbox / Se dispara al abrir en lightbox onOpen: (e) => { console.log(e.detail.image.id); // → '1' console.log(e.detail.image.caption); // → 'Mountain view' console.log(e.detail.index); // → 0 }, });
2 — Selección múltiple / Multi-selection
— haz click en imágenes para seleccionarlas —
<div id="my-gallery"></div> <script> const gallery = new MTS.ImageGallery('#my-gallery', { selectable: true, lightbox: false, images: [...], // Fires when selection changes / Se dispara al cambiar la selección onSelect: (e) => { console.log(e.detail.selected.length); // → 2 console.log(e.detail.image.id); // → last toggled }, }); gallery.getSelected() // → selected images array gallery.clearSelection() // → clear all </script>
const gallery = new MTS.ImageGallery('#my-gallery', { selectable: true, // click to select / click para seleccionar lightbox: false, // no lightbox when selecting / sin lightbox al seleccionar cols: 4, images: IMAGES, // Fires when selection changes / Se dispara al cambiar la selección onSelect: (e) => { const count = e.detail.selected.length; console.log(`${count} image(s) selected`); updateDeleteButton(count > 0); }, }); // API gallery.getSelected() // → [{ id, src, ... }, ...] gallery.clearSelection() // → clear all selected
