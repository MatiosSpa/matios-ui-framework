MTS.Tree

Árbol colapsable de jerarquías con selección, checkboxes e íconos.

1 — Básico colapsable
new MTS.Tree('#el', {
  nodes: [
    { id:'n1', label:'Proyectos', children: [
      { id:'n2', label:'Frontend', children: [
        { id:'n3', label:'index.html' },
        { id:'n4', label:'styles.css' },
      ]},
    ]},
  ],
})
2 — Selectable + onSelect
— haz click en un nodo —
new MTS.Tree('#el', {
  selectable: true,
  nodes: [...],
  onSelect: ({ node, path }) => {
    console.log(node.label, path.map(n=>n.label).join(' > '))
  },
})
3 — Checkable con propagación a hijos
— marca nodos —
const tree = new MTS.Tree('#el', {
  checkable: true,
  nodes: [...],
  onCheck: ({ node, checked, checkedIds }) => {
    console.log('marcados:', checkedIds)
  },
})
tree.getChecked()   // → ['id1', 'id2', ...]
tree.expandAll2()
tree.collapseAll()
4 — Con badges + íconos custom + sin líneas
new MTS.Tree('#el', {
  showLines: false,
  nodes: [
    { id:'n1', label:'Dashboard',  badge:3,  icon:MTS.Icon.get('home')  },
    { id:'n2', label:'Usuarios',   badge:12, icon:MTS.Icon.get('users') },
  ],
})
