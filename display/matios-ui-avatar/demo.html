MTS.Avatar

Avatar with image, initials fallback, status dot, badge and group support.

1 — Imagen, iniciales y estados / Image, initials and status
<div id="my-avatar"></div> <script> // With image / Con imagen new MTS.Avatar('#my-avatar', { src: 'photo.jpg', name: 'Ana García' }); // Initials from name (auto color) / Iniciales desde nombre (color auto) new MTS.Avatar('#my-avatar', { name: 'Pedro Martínez' }); // With status / Con estado new MTS.Avatar('#my-avatar', { name: 'Laura', status: 'online' }); // Square + badge / Cuadrado + badge new MTS.Avatar('#my-avatar', { name: 'Bot', square: true, badge: 3 }); </script>
// Image with name fallback / Imagen con fallback a nombre new MTS.Avatar('#av-img', { src: 'https://i.pravatar.cc/150?img=1', name: 'Ana García', size: 'md', }); // Initials auto-generated from name / Iniciales auto desde nombre new MTS.Avatar('#av-initials', { name: 'Pedro Martínez' }); // → 'PM' // Manual initials + custom color / Iniciales manuales + color new MTS.Avatar('#av-custom', { initials: 'JD', color: '#7c3aed' }); // Status dots / Dots de estado new MTS.Avatar('#av-online', { name: 'Laura', status: 'online' }); new MTS.Avatar('#av-busy', { name: 'Carlos', status: 'busy' }); new MTS.Avatar('#av-away', { name: 'María', status: 'away' }); new MTS.Avatar('#av-offline', { name: 'Jorge', status: 'offline' }); // Square + badge / Cuadrado + badge new MTS.Avatar('#av-square', { name: 'Bot', square: true }); new MTS.Avatar('#av-badge', { name: 'Ana', badge: 3 });

3 — AvatarGroup
<div id="my-group"></div> <script> new MTS.AvatarGroup('#my-group', { avatars: [ { src: '/img/1.jpg', name: 'Ana' }, { name: 'Pedro' }, { name: 'Laura' }, { name: 'Carlos' }, { name: 'María' }, ], max: 3, // show 3, then "+2" / mostrar 3, luego "+2" size: 'md', }); </script>
// AvatarGroup — stacked overlapping avatars new MTS.AvatarGroup('#my-group', { avatars: [ { src: 'https://i.pravatar.cc/150?img=1', name: 'Ana García' }, { src: 'https://i.pravatar.cc/150?img=2', name: 'Pedro Martínez' }, { name: 'Laura Sánchez' }, { name: 'Carlos Ruiz' }, { name: 'María Torres' }, ], max: 3, // max visible — rest shown as "+N" / máx visibles size: 'md', });
4 — API — setStatus() y setSrc()
<div id="my-avatar"></div> <script> const av = new MTS.Avatar('#my-avatar', { name: 'Ana García', size: 'lg' }); av.setStatus('online') // set status dot / establecer dot de estado av.setStatus(null) // remove dot / quitar dot av.setSrc('photo.jpg') // set image / establecer imagen av.setSrc(null) // remove image (show initials) / quitar imagen (mostrar iniciales) </script>
const av = new MTS.Avatar('#my-avatar', { name: 'Ana García', size: 'lg', }); // Update status dot / Actualizar dot de estado av.setStatus('online') // green dot av.setStatus('busy') // red dot av.setStatus('away') // yellow dot av.setStatus('offline') // gray dot av.setStatus(null) // remove dot / quitar dot // Update image / Actualizar imagen av.setSrc('https://example.com/photo.jpg') av.setSrc(null) // falls back to initials / cae a iniciales
