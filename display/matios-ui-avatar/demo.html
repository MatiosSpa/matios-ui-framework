MTS.Avatar

Avatar con imagen, iniciales automáticas, estados y grupos.

1 — Imagen, iniciales y estados
Imagen
Iniciales
Online
Busy
Away
Offline
Badge
Square 
// Con imagen
new MTS.Avatar('#el', { src:'https://...', name:'Juan Pérez', size:'md' })

// Con iniciales (auto desde name)
new MTS.Avatar('#el', { name:'María Alarcón', size:'md' })

// Con estado
new MTS.Avatar('#el', { name:'Carlos Ruiz', status:'online'  })
new MTS.Avatar('#el', { name:'Ana Torres',  status:'busy'    })
new MTS.Avatar('#el', { name:'Pedro Díaz',  status:'away'    })
new MTS.Avatar('#el', { name:'Luis García', status:'offline' })

// Con badge numérico
new MTS.Avatar('#el', { name:'Rosa Medina', badge:3 })

// Forma cuadrada
new MTS.Avatar('#el', { name:'Team', square:true })

3 — Grupo de avatares
— pasa el mouse sobre el grupo —
new MTS.AvatarGroup('#el', {
  max:  4,     // máx visibles antes de mostrar "+N"
  size: 'md',
  avatars: [
    { name:'Juan Pérez',    status:'online' },
    { name:'María Alarcón', status:'busy'   },
    { src:'https://...', name:'Carlos Ruiz' },
    { name:'Ana Torres',    status:'away'   },
    { name:'Pedro Díaz' },
    { name:'Rosa Medina' },
  ],
})
4 — API — setStatus() y setSrc()
const av = new MTS.Avatar('#el', { name:'Juan Pérez', size:'lg' })
av.setStatus('online')    // cambia el indicador de estado
av.setStatus(null)        // quita el indicador
av.setSrc('https://...')  // cambia la imagen
