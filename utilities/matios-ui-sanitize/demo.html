MTS.Sanitize v1.0

Utilidad de escape y sanitización para prevención de XSS. Sin dependencias.

MTS.Sanitize.html(str) Seguro para innerHTML

Escapa los 5 caracteres especiales HTML: & < > " ' — usar cuando el valor va dentro de una template string asignada a innerHTML.

Entrada — escribe algo
Salida escapada

MTS.Sanitize.attr(str) Seguro para atributos

Como html() pero además escapa el backtick. Usar en title, aria-label, data-*, etc.

Entrada — escribe algo
Salida escapada

MTS.Sanitize.url(str) Bloquea javascript: data: vbscript:

Permite https://, http://, rutas relativas y protocolo relativo //. Retorna '' si la URL es peligrosa.

MTS.Sanitize.text(str) Para textContent

Convierte cualquier valor a string, manejando null y undefined como cadena vacía. Semánticamente indica que el valor irá a textContent.
