# Data

🇬🇧 Components for presenting and loading tabular data and collections. They complement the `widgets/datatable` widget for simpler use cases or infinite scroll requirements.
🇪🇸 Componentes para presentación y carga de datos tabulares y colecciones. Complementan al widget `widgets/datatable` para casos de uso más simples o con requerimientos de scroll infinito.

---

## Components / Componentes

| Componente | Clase JS | 🇬🇧 Description / 🇪🇸 Descripción |
|---|---|---|
| `matios-ui-infinite` | `MTS.Infinite` | 🇬🇧 Infinite scroll with developer-controlled incremental loading. Compatible with vertical and horizontal layouts. / 🇪🇸 Scroll infinito con carga incremental controlada por el desarrollador. Compatible con layouts verticales y horizontales. |
| `matios-ui-table` | — (CSS) | 🇬🇧 Pure CSS table — no JavaScript required. Variants, cell states, fixed header and responsive layout. / 🇪🇸 Tabla CSS pura — sin JavaScript requerido. Variantes, estados de celda, fixed header y diseño responsivo. |

---

## Notes / Notas

- 🇬🇧 `matios-ui-table` is CSS-only — ideal for simple static tables or server-side rendered content. / 🇪🇸 `matios-ui-table` es CSS puro — ideal para tablas simples estáticas o renderizadas server-side.
- 🇬🇧 For tables with server-side pagination, sorting, filters and advanced plugins use `widgets/datatable` (`MTS.DataTable`). / 🇪🇸 Para tablas con paginación server-side, sorting, filtros y plugins avanzados usar `widgets/datatable` (`MTS.DataTable`).
- 🇬🇧 `MTS.Infinite` can be combined with any container — it is not coupled to `matios-ui-table`. / 🇪🇸 `MTS.Infinite` puede combinarse con cualquier contenedor — no está acoplado a `matios-ui-table`.
