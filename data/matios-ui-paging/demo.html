MTS.Paging

Standalone pagination — page size selector, info text, server response integration.

1 — Configuración completa / Full config
— navega las páginas —
<div id="my-pager"></div> <script> const pager = new MTS.Paging('#my-pager', { total: 150, page: 1, pageSize: 10, // Fires on any change — most useful / Se dispara en cualquier cambio onChange: (e) => { console.log(e.detail.page); // → 2 console.log(e.detail.pageSize); // → 10 loadData(e.detail.page, e.detail.pageSize); }, }); </script>
const pager = new MTS.Paging('#my-pager', { total: 150, page: 1, pageSize: 10, pageSizes: [10, 25, 50, 100], maxVisible: 5, showInfo: true, showPageSize: true, showEdges: true, variant: 'primary', // Fires on any page/size change / Se dispara en cualquier cambio de página o tamaño onChange: (e) => { console.log(e.detail.page, e.detail.pageSize); fetchData(e.detail.page, e.detail.pageSize); }, // Fires on next specifically / Se dispara específicamente al avanzar onNext: (e) => console.log('next:', e.detail.page), // Fires on prev specifically / Se dispara específicamente al retroceder onPrev: (e) => console.log('prev:', e.detail.page), // Fires on page number click / Se dispara al hacer click en número de página onPageClick: (e) => console.log('page:', e.detail.page), // Fires on page size change / Se dispara al cambiar el tamaño de página onPageSizeChange:(e) => console.log('size:', e.detail.pageSize), });
2 — API + variantes / API + variants
— usa los botones —
<div id="my-pager"></div> <script> const p = new MTS.Paging('#my-pager', { total: 150 }); p.setPage(3) // jump to page / saltar a página p.next() // advance / avanzar p.prev() // go back / retroceder p.setTotal(200) // update total / actualizar total p.setPageSize(25) // change page size / cambiar tamaño p.getState() // → { page, pageSize, total, totalPages } p.setResponse({...}) // from server response / desde respuesta del servidor </script>
// Variants / Variantes new MTS.Paging('#pager-primary', { total:150, variant:'primary', onChange:(e)=>log(e) }); new MTS.Paging('#pager-ghost', { total:150, variant:'ghost', onChange:(e)=>log(e) }); new MTS.Paging('#pager-sm', { total:150, variant:'primary', size:'sm', showInfo:false, showPageSize:false }); // API const p = new MTS.Paging('#my-pager', { total: 150 }); p.setPage(3) p.next() p.prev() p.setTotal(200) p.setPageSize(25) p.getState() // → { page:3, pageSize:25, total:200, totalPages:8 } // Server response integration / Integración con respuesta del servidor p.setResponse({ page: 2, pageSize: 10, total: 150, totalPages: 15, hasNext: true, hasPrev: true, });
