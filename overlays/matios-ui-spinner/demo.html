MTS.Spinner

Animated loading indicators — circle, dots, bars, pulse, ring · 5 sizes · overlay mode.

1 — Variantes / Variants
<div id="my-spinner"></div> <script> new MTS.Spinner('#my-spinner', { variant: 'circle', // 'circle' | 'dots' | 'bars' | 'pulse' | 'ring' size: 'md', }); </script>
// Variants: 'circle' | 'dots' | 'bars' | 'pulse' | 'ring' ['circle', 'dots', 'bars', 'pulse', 'ring'].forEach(variant => { new MTS.Spinner('#spinner-' + variant, { variant, size: 'md', }); });
2 — Tamaños / Sizes
<div id="my-spinner" data-variant="circle" data-size="lg"></div> <script> new MTS.Spinner('#my-spinner'); </script>
// Sizes: 'xs' | 'sm' | 'md' | 'lg' | 'xl' ['xs', 'sm', 'md', 'lg', 'xl'].forEach(size => { new MTS.Spinner('#spinner-size-' + size, { variant: 'circle', size, }); });
