MTS.Modal

Dialog modal — sizes, footer buttons, scrollable, static, confirm/alert/prompt helpers.

1 — Tamaños / Sizes
— abre un modal —
<!-- MTS.Modal appends to body — no HTML container needed MTS.Modal se agrega al body — no necesita contenedor HTML --> <button onclick="modal.show()">Open modal</button> <script> const modal = new MTS.Modal({ title: 'Edit user', body: '<div id="form"></div>', size: 'md', buttons: [ { label: 'Cancel', variant: 'ghost', close: true }, { label: 'Save', variant: 'primary', onClick: () => save() }, ], // Fires after modal is fully visible / Se dispara al estar completamente visible onShown: () => initForm(), // Fires after modal is fully hidden / Se dispara al estar completamente oculto onHidden: () => console.log('closed'), }); </script>
// Sizes: 'sm' | 'md' | 'lg' | 'xl' | 'fullscreen' const modal = new MTS.Modal({ title: 'Modal title', body: '<p>Modal body content.</p>', size: 'md', // change to see different sizes buttons: [ { label: 'Cancel', variant: 'ghost', close: true }, { label: 'Accept', variant: 'primary', close: true, onClick: () => console.log('accepted') }, ], // Fires before showing / Se dispara antes de mostrar onShow: () => console.log('about to show'), // Fires after fully shown / Se dispara al estar completamente visible onShown: () => console.log('shown'), // Fires after fully hidden / Se dispara al estar completamente oculto onHidden: () => console.log('hidden'), }); modal.show();
2 — Helpers rápidos / Convenience helpers
— usa los helpers —
<script> // Confirm dialog / Diálogo de confirmación MTS.Modal.confirm({ title: 'Delete record', message: 'This action cannot be undone.', confirm: 'Delete', cancel: 'Cancel', danger: true, onConfirm: () => deleteRecord(), onCancel: () => console.log('cancelled'), }); // Simple alert / Alerta simple MTS.Modal.alert({ title: 'Done', message: 'Record saved successfully.', }); // Prompt with input / Prompt con input MTS.Modal.prompt({ title: 'Rename', placeholder: 'New name...', onConfirm: (value) => rename(value), }); </script>
// Confirm dialog / Diálogo de confirmación MTS.Modal.confirm({ title: 'Delete record', message: 'This action cannot be undone.', confirm: 'Delete', cancel: 'Cancel', danger: true, // Fires on confirm / Se dispara al confirmar onConfirm: () => console.log('confirmed'), // Fires on cancel / Se dispara al cancelar onCancel: () => console.log('cancelled'), }); // Alert / Alerta MTS.Modal.alert({ title: 'Done', message: 'Your changes were saved.', onClose: () => console.log('acknowledged'), }); // Prompt — input dialog / Diálogo con input MTS.Modal.prompt({ title: 'Rename file', placeholder: 'New name...', value: 'document.pdf', // Fires with the entered value / Se dispara con el valor ingresado onConfirm: (value) => console.log('new name:', value), });
3 — Static + scrollable body
<!-- Static — only closes via button / Solo cierra con botón --> <script> new MTS.Modal({ title: 'Required action', body: '<p>You must complete this step.</p>', static: true, // no Esc, no backdrop click buttons: [{ label: 'OK', variant: 'primary', close: true }], }).show(); </script> <!-- Scrollable body / Body scrolleable --> <script> new MTS.Modal({ title: 'Terms of service', body: longContent, size: 'lg', scrollable: true, }).show(); </script>
// Static — no close on Esc or backdrop / Sin cierre con Esc ni backdrop new MTS.Modal({ title: 'Required action', body: '<p>You must complete this step before continuing.</p>', static: true, buttons: [ { label: 'Complete later', variant: 'ghost', close: true }, { label: 'Do it now', variant: 'primary', close: true }, ], }).show(); // Scrollable body / Body con scroll new MTS.Modal({ title: 'Terms of service', size: 'lg', scrollable: true, // body scrolls, header/footer stay fixed body: '<p>' + 'Long text... '.repeat(100) + '</p>', buttons: [ { label: 'Decline', variant: 'ghost', close: true }, { label: 'Accept', variant: 'primary', close: true }, ], }).show();
