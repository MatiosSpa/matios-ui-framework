MTS.Alert

Inline alerts and banners — variants, icons, action buttons, auto-dismiss.

1 — Variantes / Variants
— cierra una alerta —
<div id="my-alert"></div> <script> new MTS.Alert('#my-alert', { variant: 'success', title: 'Saved', message: 'Changes saved correctly.', // Fires when closed / Se dispara al cerrar onClose: (e) => console.log('closed'), }); </script>
// Info (default) new MTS.Alert('#alert-info', { variant: 'info', title: 'New version available', message: 'Update to get the latest features.', onClose: (e) => console.log('info closed'), }); // Success new MTS.Alert('#alert-success', { variant: 'success', title: 'Changes saved', message: 'Your data was saved correctly.', onClose: (e) => console.log('success closed'), }); // Warning new MTS.Alert('#alert-warning', { variant: 'warning', title: 'Session expiring', message: 'Your session expires in 5 minutes.', onClose: (e) => console.log('warning closed'), }); // Danger new MTS.Alert('#alert-danger', { variant: 'danger', title: 'Connection error', message: 'Could not connect to the server.', onClose: (e) => console.log('danger closed'), });
2 — Con acción y auto-dismiss / With action and auto-dismiss
— usa los botones —
<div id="my-alert"></div> <script> // With action button / Con botón de acción new MTS.Alert('#my-alert', { variant: 'warning', message: 'Session expires soon.', action: 'Renew', // Fires on action click / Se dispara al hacer click en la acción onAction: (e) => renewSession(), onClose: (e) => console.log('dismissed'), }); // Auto-dismiss after 3s / Auto-cerrar tras 3s new MTS.Alert('#my-alert', { variant: 'success', message: 'File uploaded successfully.', autoDismiss: 3000, closable: false, }); </script>
// With action button / Con botón de acción new MTS.Alert('#my-alert', { variant: 'warning', title: 'Session expiring', message: 'Your session expires in 5 minutes.', action: 'Renew now', // Fires when action button is clicked / Se dispara al hacer click en la acción onAction: (e) => console.log('action clicked'), onClose: (e) => console.log('dismissed'), }); // Auto-dismiss / Auto-cerrar new MTS.Alert('#my-alert', { variant: 'success', message: 'File uploaded successfully.', autoDismiss: 3000, // closes after 3s / cierra tras 3s closable: false, // no close button / sin botón de cierre });
