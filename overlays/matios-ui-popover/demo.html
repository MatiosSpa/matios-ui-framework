MTS.Popover

Rich tooltip — title, HTML body, arrow, positions, click/hover trigger.

1 — Posiciones / Positions (click trigger)
— haz click en un botón —
<button id="btn-help">Help</button> <script> new MTS.Popover('#btn-help', { title: 'What is this?', content: '<p>This field requires a valid email.</p>', position: 'bottom', trigger: 'click', // Fires when popover shows / Se dispara al mostrar onShow: (e) => console.log('shown'), // Fires when popover hides / Se dispara al ocultar onHide: (e) => console.log('hidden'), }); </script>
const CONTENT = '<p style="font-size:13px;color:var(--mts-text-muted)">This is a popover with <strong>HTML content</strong> and smart positioning.</p>'; // Position: 'top' | 'bottom' | 'left' | 'right' new MTS.Popover('#btn-top', { title: 'Top', content: CONTENT, position: 'top' }); new MTS.Popover('#btn-bottom', { title: 'Bottom', content: CONTENT, position: 'bottom' }); new MTS.Popover('#btn-left', { title: 'Left', content: CONTENT, position: 'left' }); new MTS.Popover('#btn-right', { title: 'Right', content: CONTENT, position: 'right' }); // All with events / Todos con eventos new MTS.Popover('#btn-events', { title: 'With events', content: CONTENT, // Fires when shown / Se dispara al mostrar onShow: (e) => console.log('shown'), // Fires when hidden / Se dispara al ocultar onHide: (e) => console.log('hidden'), });
2 — Hover + contenido HTML rico / HTML content + hover
<!-- Hover trigger / Trigger hover --> <button id="btn-hover">Hover me</button> <script> new MTS.Popover('#btn-hover', { title: 'Pro tip', content: '<p>Use <kbd>⌘S</kbd> to save quickly.</p>', trigger: 'hover', position:'top', }); </script> <!-- HTML declarativo / Declarative HTML --> <button id="my-btn" data-title="Help" data-content="Contact us at help@example.com" data-position="bottom"> Help </button> <script> new MTS.Popover('#my-btn'); </script>
