MTS.Popover

Tooltip enriquecido con título, contenido HTML, flecha y cierre.

1 — Click trigger — posiciones
new MTS.Popover('#btn', {
  title:    'Título del popover',
  content:  '
Contenido HTML con formato.
',
  position: 'bottom',   // 'top'|'bottom'|'left'|'right'
  trigger:  'click',
})
2 — Hover + sin cerrar (closable:false)
— interactúa —
new MTS.Popover('#btn', { trigger:'hover', content:'...' })
new MTS.Popover('#btn', { closable:false, content:'...' })
new MTS.Popover('#btn', { arrow:false, content:'...' })
HTML declarativo
— abre el popover —
<button id="miBtn" data-title="Info" data-content="Contenido." data-position="top" data-trigger="click" data-closable>Info</button>
<script>new MTS.Popover('#miBtn', { onShow: () => console.log('abierto') })</script>
