MTS.Toast

Notificaciones fugaces con variantes, posiciones, acciones y barra de progreso.

1 — Variantes
MTS.Toast.show({ message:'Guardado', variant:'success', title:'Éxito' })
MTS.Toast.show({ message:'Revisa los datos', variant:'warning' })
MTS.Toast.show({ message:'Error al conectar', variant:'danger' })
MTS.Toast.show({ message:'Actualización disponible', variant:'info' })

// Atajos rápidos
MTS.Toast.show.success('Guardado correctamente')
MTS.Toast.show.danger('Error al procesar')
2 — Posiciones
MTS.Toast.show({
  message:  'Toast en top-right',
  position: 'top-right',   // 'top-left'|'top-center'|'top-right'
                            // 'bottom-left'|'bottom-center'|'bottom-right'
  variant:  'info',
})
3 — Con acción y duración personalizada
// Con botón de acción
MTS.Toast.show({
  message:  'Se eliminaron 3 archivos.',
  variant:  'warning',
  action:   'Deshacer',
  onAction: () => console.log('deshacer'),
  duration:  8000,
})

// Persistente — no cierra hasta que el usuario lo cierre
const t = MTS.Toast.show({ message: 'Procesando...', duration: 0 })
// Cerrar programáticamente
t.close()

// Duración custom
MTS.Toast.show({ message: 'Guardado', variant:'success', duration: 1500 })
