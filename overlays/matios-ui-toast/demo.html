MTS.Toast

Transient notifications — variants, positions, action button, loading state. Static API.

1 — Variantes / Variants
<!-- MTS.Toast is a static API — no HTML container needed MTS.Toast es una API estática — no necesita contenedor HTML --> <button onclick="MTS.Toast.show({ variant: 'success', message: 'Saved!' })"> Show toast </button>
// Static API — call directly / API estática — llamar directamente MTS.Toast.show({ message: 'Default notification' }); MTS.Toast.show({ variant: 'success', message: 'File saved successfully.' }); MTS.Toast.show({ variant: 'warning', message: 'Low disk space remaining.' }); MTS.Toast.show({ variant: 'danger', message: 'Connection failed.', duration: 0 }); MTS.Toast.show({ variant: 'info', message: 'New version available.' }); // With title / Con título MTS.Toast.show({ variant: 'warning', title: 'Low storage', message: 'Only 2GB remaining.', duration: 6000, // Fires when closed / Se dispara al cerrar onClose: (e) => console.log('dismissed'), });
2 — Posiciones / Positions
<script> MTS.Toast.show({ variant:'success', message:'Saved!', position:'top-center' }); MTS.Toast.show({ variant:'danger', message:'Error!', position:'bottom-left' }); </script>
// 6 positions / 6 posiciones MTS.Toast.show({ message: 'Top right', position: 'top-right' }); // default MTS.Toast.show({ message: 'Top center', position: 'top-center' }); MTS.Toast.show({ message: 'Top left', position: 'top-left' }); MTS.Toast.show({ message: 'Bottom right', position: 'bottom-right' }); MTS.Toast.show({ message: 'Bottom center', position: 'bottom-center' }); MTS.Toast.show({ message: 'Bottom left', position: 'bottom-left' });
3 — Acción + loading state
— usa los botones —
<script> // With action button / Con botón de acción MTS.Toast.show({ variant: 'info', message: 'New version available.', action: 'Update now', // Fires on action click / Se dispara al hacer click en la acción onAction: () => installUpdate(), onClose: () => console.log('dismissed'), }); // Loading → then close / Loading → luego cerrar const loader = MTS.Toast.show({ variant: 'loading', message: 'Uploading file...', duration: 0, // does not auto-close / no cierra automáticamente closable: false, }); setTimeout(() => { loader.close(); MTS.Toast.show({ variant: 'success', message: 'Upload complete!' }); }, 3000); </script>
// With action button / Con botón de acción MTS.Toast.show({ variant: 'info', title: 'Update available', message: 'Version 2.0 is ready.', action: 'Install now', duration: 0, // stays until action or close / permanece hasta acción o cierre // Fires when action is clicked / Se dispara al hacer click en la acción onAction: (e) => console.log('install triggered'), // Fires when closed / Se dispara al cerrar onClose: (e) => console.log('dismissed'), }); // Loading state → then close / Estado loading → luego cerrar const loader = MTS.Toast.show({ variant: 'loading', message: 'Uploading file...', duration: 0, // does not auto-close / no cierra automáticamente closable: false, // no close button / sin botón de cierre }); // Close manually when done / Cerrar manualmente al terminar setTimeout(() => { loader.close(); MTS.Toast.show({ variant: 'success', message: 'Upload complete!' }); }, 3000); // Returns { close() } / Retorna { close() } const toast = MTS.Toast.show({ message: 'Processing...' }); toast.close(); // close programmatically / cerrar programáticamente
