MTS.Tooltip

Tooltip con posicionamiento inteligente, triggers y colores custom.

1 — Posiciones
new MTS.Tooltip('#el', {
  content:  'Texto del tooltip',
  position: 'top',      // 'top'|'right'|'bottom'|'left'
  trigger:  'hover',    // default
})
2 — Triggers
new MTS.Tooltip('#el', { content:'Click para abrir', trigger:'click'  })
new MTS.Tooltip('#el', { content:'Focus aquí',      trigger:'focus'  })
new MTS.Tooltip('#el', { content:'Aparezco tarde',  delay:400, hideDelay:200 })
3 — Variantes y colores
new MTS.Tooltip('#el', { content:'Dark',    variant:'dark'  })   // default
new MTS.Tooltip('#el', { content:'Light',   variant:'light' })
// Color custom via bg + color
new MTS.Tooltip('#el', { content:'✅ Éxito', bg:'#052e16', color:'#34d399' })
new MTS.Tooltip('#el', { content:'⚠️ Alerta',bg:'#2d1b00', color:'#fbbf24' })
new MTS.Tooltip('#el', { content:'🗑 Eliminar',bg:'#1a0404',color:'#f87171' })
4 — Con HTML y eventos
— pasa el mouse por los botones —
// HTML en el contenido
new MTS.Tooltip('#el', {
  content: '<strong>Título</strong><br>Descripción detallada aquí.',
  maxWidth: 200,
})

// Eventos show/hide
new MTS.Tooltip('#el', {
  content: 'Con eventos',
  onShow: (e) => console.log('shown'),
  onHide: (e) => console.log('hidden'),
})
5 — initAll() — desde atributos HTML
<!-- Agregar atributos HTML — sin JS adicional -->
<button data-tooltip="Tooltip desde HTML"
        data-tooltip-position="top">
  Mi botón
</button>

// Inicializar todos al cargar
MTS.Tooltip.initAll()
HTML declarativo
<button id="miBtn" data-content="Guardar cambios" data-position="top">💾</button>
<script>new MTS.Tooltip('#miBtn')</script>
